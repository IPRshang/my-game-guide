# 隐私政策

最后更新：2026-08-09

欢迎访问「热门游戏攻略站」（以下简称"本站"）。本站致力于提供 GTA6、Arknights: Endfield、Neverness to Everness等热门游戏的原创攻略内容。本站高度重视您的隐私，本政策说明我们如何处理与您相关的信息。

## 一、我们收集的信息

- **您主动提供的信息**：当您使用本站评论功能（基于 Giscus，由 GitHub 账号授权）时，您授权的昵称与头像可能会随评论展示。我们不会要求您提供真实姓名、电话或身份证等个人敏感信息。
- **自动收集的信息**：本站通过百度统计（Baidu Analytics）收集匿名化的访问数据（如页面浏览量、来源、设备类型、大致地域），用于了解内容受欢迎程度并改进站点。这些数据不包含可直接识别个人的信息。

## 二、Cookie 与广告

本站使用 **Google AdSense** 展示广告以获得运营支持。AdSense 及其合作伙伴可能通过 **Cookie**、Web Beacon 等技术与您的浏览器交互，用于：

- 投放与您兴趣相关的广告（个性化广告）；
- 衡量广告效果与防止广告欺诈。

相关 Cookie 可能由 Google 及第三方广告商设置，典型包括 `NID`、`IDE`、`__gads`、`__ga` 等。这些 Cookie 的存储与管理受 Google 及相应广告商的隐私政策约束。

**您的选择权**：您可以通过以下方式管理广告个性化与 Cookie：
- Google 广告设置：https://www.google.com/settings/ads
- 您的浏览器设置中清除或禁用 Cookie；
- 欧盟用户可通过 YourOnlineChoices（http://www.youronlinechoices.com/）退出第三方广告 Cookie。

## 三、第三方服务与联盟营销

本站可能包含指向第三方网站（如游戏官网、商店、视频平台）的链接。这些网站有独立的隐私政策，本站不对它们的内容或数据处理负责。

本站部分内容（如装备推荐、购买链接）可能包含**联盟营销链接**（例如淘宝联盟、京东联盟）。当您通过此类链接购买商品时，本站可能获得少量佣金，但**商品售价不会因此增加**。联盟合作方可能会通过 Cookie 追踪转化，具体请参见其隐私政策。

## 四、儿童隐私

本站内容面向一般游戏玩家，不针对 13 岁以下儿童定向收集信息。如您是监护人并认为您的孩子向我们提供了个人信息，请联系我们处理。

## 五、联系我们

如对本隐私政策有疑问，可通过本站评论区或项目仓库（GitHub: IPRshang/my-game-guide）与我们联系。
