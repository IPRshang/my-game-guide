### 1.2 为什么「An Extended Look」是近年最重要一爆

- 自 2025 年 5 月 Trailer 2 后，Rockstar 进入长约 15 个月的静默；
- Take-Two CEO 此前预告「2026 夏季开启主宣发」，8/27 正是这一波的起点；
- 外界普遍预期这是**首次展示真实 gameplay**（前两段偏电影化），可能首秀驾驶 / 战斗 / 通缉 / 都市生态；
- 史无前例：Rockstar 首次把 trailer 交给 **Netflix 首映**，主宣发正式点火。

### 1.3 地图与城市（深度）

- 基于泄露（CyberLeek 等，**未官方确认**）：**Leonida 约 125 km²**（约 GTA V 两倍），含以 **Vice City** 为首的六区；
- 已浮现新命名：**Vice-Dale County、Kelly County、Mount Kalaga、Ambrosia** 等；
- 6 星通缉系统回归、**Honor / Karma** 道德机制等（泄露内容，标注「未官方确认」）。
- 深度详见 [GTA6 地图与城市指南](/gta6/map-guide) 与 [泄露情报汇总](/gta6/leaks)。

- 系列首次双主角，Lucia 为首位女性可玩主角；
- 故事围绕二人关系与 Leonida 的犯罪世界展开。详见 [GTA6 角色系统](/gta6/character-guide)。
