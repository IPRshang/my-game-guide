## 一、一站式全貌：Ananta 到底是什么？

### 1.1 基本盘

| 项目 | 内容 |
|------|------|
| 开发 / 发行 | 网易（NetEase）+ Naked Rain 工作室（杭州，约 800 人） |
| 类型 | 都市开放世界 anime RPG，常被称作 **「anime GTA」** |
| 舞台 | **Nova City**——超自然现象与日常生活并存的现代都市 |
| 玩家身份 | 代号 **Infinite Trigger** 的 Esper（超能力者）调查员，隶属 **A.C.D.（反混沌部门）** |
| 平台 | PlayStation 5、PlayStation 4、PC（预计走 Steam）、iOS、Android |
| 定价 | **免费游玩（free-to-play）** |
| 预注册 | 已突破 **1700 万** |

### 1.2 三年时间线（full-circle 叙事点）

- **2023-08-24**：以开发代号 **Project Mugen** 在 Gamescom 首次公布，惊艳全场；
- **2024-11 / 12-05**：正式更名 **Ananta**（梵语「无限 / 没有尽头」）；
- **2025-09**：Tokyo Game Show 放出首支实机，被外媒直接拿来和 **GTA6** 比较；
- **2026-08-25（今天）**：以 **Ananta** 之名重回 Gamescom 开幕夜，带来「约一年来首次新画面」。

整整三年，同一展会，从代号到正式名——这是 Ananta 粉丝今年最该守的一晚。

### 1.3 玩法拆解（深度）

Ananta 的核心卖点是 **「移动即玩法」**，官方物料展示的系统包括：

- **都市穿行**：Spider-Man 式缆绳摆荡、跑酷、墙爬、骑车开车、游泳，**全程不消耗体力条**；Taffy 的锤子还能直接变自行车（战斗与移动一体化）。
- **街头格斗**：闪避（dodge）、反击（counter）、武术连段，自由流畅；还能捡起**临时武器**——高尔夫球杆、网球拍、大锤都上了画面，颇有几分《Sleeping Dogs》的味道。
- **黑客系统**：带有 Watch_Dogs 式的侵入 / 信息玩法，呼应 Nova City 的都市设定。
- **城市生活**：街机、拍照、撸猫等几十个迷你游戏，叠加昼夜循环，构成一个「活着的城市」。
- **角色驱动叙事**：玩家带领 **四人小队**，在 A.C.D. 体制内调查超自然异常——你不是外来旅人，而是城市体制内的调查者。

> 💡 这套组合拳的差异化在于：**移动自由度极高 + 角色全免费（传闻）+ anime 美术**，更偏「GTA 都市沙盒 + 二次元角色驱动」，而非传统抽卡 ARPG。

### 1.4 角色图鉴（已知四人 + 玩家）

| 角色 | 已确认定位 |
|------|-----------|
| **Captain** | A.C.D. 领导者（社区常拿他和《鸣潮》漂泊者做外形对比，属玩家观感） |
| **Taffy** | Yeet 小队成员，锤子可变形为自行车 |
| **Richie** | 资深专业人士（经验 / 技术维度） |
| **Seymour** | 黑客（信息 / 网络层介入） |
| **Infinite Trigger** | 玩家角色，A.C.D. Esper 调查员 |

四人覆盖了**指挥 / 机动 / 经验 / 技术**四个方向，构成职能清晰的调查团队骨架。完整设定见 [Ananta 角色图鉴](/ananta/characters)。

### 1.5 商业化：传闻 vs 确认（重点区分）

这是社区最容易传歪的一块，本站已专门拆过：

- **已确认**：免费游玩、五平台、1700 万预注册、Naked Rain 开发。
- **传闻（网易未官宣）**：不设抽卡、所有角色免费获取、仅通过外观（cosmetics）变现。日媒称角色获取不靠限时卡池，付费集中在皮肤 / 载具 / 家具。

⚠️ **请勿把「无抽卡」当官方事实**——免费游玩 ≠ 无抽卡，上线前设计仍可能调整。开发方曾在 2025 年底采访中表达过「不打算实现角色抽卡」的意向，但**网易从未发布正式声明**。完整信息边界见 [Ananta 商业化：已确认 vs 传闻](/ananta/monetization)。

### 1.6 状态与发售窗口

- **是否跳票 / 被砍？** 已辟谣。长期静默期社区确有担忧，但 ONL 回归确认游戏**活着且在推进**。时间线梳理见 [Ananta 是否跳票 / 被砍？](/ananta/is-it-cancelled)。
- **发售日**：Famitsu（TGS 2025 特辑）将其列为 **2026 窗口**，但网易从未承诺具体日期；分析师（如 JPMorgan）已把预期下修到 **2027 上半年**。今晚 ONL 可能给档期，也可能只是新画面 + 更长等待。

## 五、常见问题（FAQ）

**Q：今晚（8/25）一定能看到实机演示吗？**
A：Keighley 确认是「a fresh look」，多家媒体预期含 gameplay；是否给发售日未知，值得全程跟播。

**Q：Ananta 要花钱抽角色吗？**
A：目前是传闻——日本媒体报道「无抽卡、全角色免费」，开发方曾表达过类似意向，但**网易从未官方确认**。已确认的只有「免费游玩」。详见 [商业化页](/ananta/monetization)。

**Q：Ananta 和 Project Mugen 是同一款吗？**
A：是。Project Mugen 是 2023 年公布时的开发代号，2024 年底更名 Ananta。

**Q：国内怎么看直播？**
A：北京时间 8/26 02:00，搜官方 gamescom YouTube / Twitch / Steam 频道；或等直播后官方录播（次日早晨）。

**Q：预注册有奖励吗？**
A：网易尚未公布里程碑奖励档位，建议先占坑，开幕夜后关注官方首发福利。

**Q：发售日定了吗？**
A：未定。Famitsu 列 2026 窗口，行业预期偏向 2027 上半年，以今晚 ONL 为准。
