## 📅 今日推荐

### 🏁 Forza Horizon 6（极限竞速：地平线 6）

- **类型**：开放世界竞速 / 赛车
- **平台**：Xbox Series X|S · PC（Microsoft Store / Steam）
- **评分**：Metacritic 91（媒体均分，2026）
- **一句话**：把"开车兜风"做成一种生活态度的开放世界竞速神作。

**为什么推荐它**
地平线系列一直把"自由驾驶"的乐趣放在拟真之上。第六代在墨西哥风光的开放世界基础上，进一步强化了天气动态、车辆与环境的互动，以及随时随地开一局的低门槛。无论你是硬核赛车党还是只想看风景的休闲玩家，都能找到自己的节奏。

**核心亮点**
- 🌤️ 动态季节与天气：同一张地图，不同季节是完全不同的驾驶体验。
- 🚗 海量车辆授权：从经典肌肉车到超跑，收集与改装深度足够。
- 🎵 音乐节氛围：电台+BGM 让长途驾驶不枯燥。
- 👥 低门槛联机：好友房间、巡回赛、限时活动随手开。

**适合谁**
- 想放松、不想被剧情压力的玩家；
- 喜欢"边听歌边看风景"的休闲党；
- 竞速老饕（拟真手感可调，从街机到硬核都能玩）。

**购买建议**
首发加入 Game Pass 可先试后买；长期玩建议直接购入终极版以解锁后续车辆通行证。
