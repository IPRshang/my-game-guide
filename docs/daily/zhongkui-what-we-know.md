# 黑神话：钟馗 深度前瞻：我们已知的一切与合理猜想

继 [《黑神话：悟空》](/zhongkui/vs-wukong) 全球大爆之后，Game Science 在 **2025 科隆游戏展开幕式（Gamescom Opening Night Live）** 抛出重磅：下一部「黑神话」系列作品——《**黑神话：钟馗**》（Black Myth: Zhong Kui）正式官宣。本篇把**已经确认的事实**与**社区合理猜想**分开讲清，并附上发售窗口、平台、与前作关系的判断，帮你判断这款神话新作值不值得蹲。

> 结论先行：目前**只有一支电影化预告片**，没有实机、没有平台、没有发售日。任何「配置要求」「玩法系统」都属猜想，下文会明确标注。

## 二、与前作《悟空》是什么关系？

这是玩家问得最多的问题。基于官宣信息与业界惯例，可以给出三层判断：

1. **同一品牌，大概率不是直接续作**：「黑神话」更像是一个以中国神话为母题的**作品矩阵**，每一部聚焦一位神祇 / 一段传说，而非线性续作。钟馗与悟空分属不同神话谱系。
2. **技术 lineage 大概率延续**：《悟空》用的是 **UE5 + 自研动作捕捉 / 扫描资产管线**，钟馗作为同厂续作，沿用这套工业化管线几乎是板上钉钉。
3. **叙事是否共享宇宙**：官方未说明。保守判断为**独立故事、共享「黑神话」美学与制作水准**，而非《悟空》结局的直接延续。

更深入的对比见 [钟馗 vs 悟空](/zhongkui/vs-wukong)。

## 三、合理猜想（标注：未官方确认）

以下内容为基于《悟空》与行业规律的推测，**请勿当作官方信息**：

- **引擎与画面**：几乎确定继续基于 UE5，画面水准对标《悟空》甚至更高；
- **玩法**：动作 RPG 方向概率最高（与《悟空》一致），但是否沿用「棍法 + 法术 + 变身」体系未知；
- **题材展开**：钟馗「驱邪斩鬼」的设定，天然适配「降妖除魔」式关卡与 Boss 战，可能比《悟空》更偏「志怪 / 捉鬼」；
- **平台**：参考《悟空》首发 PS5 / PC，钟馗大概率同样**主机 + PC 双线**，是否上 Xbox 待官宣；
- **语言 / 配音**：大概率延续《悟空》的**全中文演出 + 多语字幕**路线。

## 四、发售窗口怎么看？

- **官方状态**：截至 2026-09，**无任何发售日或平台官宣**；
- **合理预期**：以《悟空》（2020 立项 → 2024 发售，约 4 年）为参照，钟馗从 2025 官宣算起，普遍预期 **2027 年及以后**更现实，但 Game Science 节奏不可预测；
- **蹲点建议**：盯紧每年 **Gamescom Opening Night Live** 与 **TGA（The Game Awards）** 两个节点，重大消息几乎都在这类舞台放出。
