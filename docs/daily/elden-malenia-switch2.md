# 艾尔登法环 玛莲妮亚怎么打（水鸟乱舞·出血流·全Boss速查）

《艾尔登法环》（Metacritic **96 分**，2022 年度最高分、TGA 年度游戏）是有史以来最火的魂类开放世界，而**女武神玛莲妮亚**被公认为全游戏最难 Boss。据官方统计，她已累计击杀褪色者超过 **3 亿次**。本篇把已删攻略里的高价值内容复活编排，重点做透「玛莲妮亚怎么打 / 水鸟乱舞」，并附全 Boss 速查、DLC 简介与 Switch2 前瞻，一次读完即能上手。

## 一、玛莲妮亚 开打前准备

| 项目 | 推荐 |
|------|------|
| 推荐等级 | **120–130**（血量 50+ 更稳） |
| 推荐流派 | **出血流**（快速压血线，减少她出招次数） |
| 骨灰 | **仿身泪滴（人偶）**——最稳，能分担水鸟锁定 |
| 护符 | 龙徽大盾、大壶众武、腐败眷属的欢愉 |
| 关键道具 | 净化苔藓（吃猩红腐败）、冰霜壶（打断水鸟起手） |

> ⚠️ **致命机制**：玛莲妮亚的**回血**——任何攻击命中你（含举盾格挡）、甚至你的骨灰被击中，都会给她回血。因此**不要用「黑刀狄希」**这类会被持续打中的骨灰，否则血线永远压不下去。

## 二、水鸟乱舞三段怎么躲（核心）

水鸟乱舞是她的招牌杀招，分三段，最稳应对如下（练熟即可无伤）：

1. **起手 · 跳向空中**：她跃起瞬间**立即向外跑远**，拉开距离。
2. **第一段 · 落剑**：第一段落下时**向外翻滚**，保持距离躲开第一波剑花。
3. **第二段 · 突进**：她向前突刺时**向前翻滚穿过她身体**，贴到背后即可避掉。
4. **第三段 · 收尾剑花**：最后一段前冲，向后翻滚脱离剑花范围。

> 新手技巧：在她出水鸟**前摇**时扔「冰霜壶」，可打出冻伤使其坠落硬直；或用「冻霜踏地」、远程法术提前压血，逼她早进二阶段降低水鸟触发频率。

## 三、出血流配装（降维打击）

| 部位 | 推荐 |
|------|------|
| 武器 | **双剥尸曲剑** + 战灰「切腹」+ 白面具 + 鲜血君王的欢愉 |
| 备选 | 尸山血海（尸横遍野）、艾琉诺拉双头刀 |
| 加点 | 生命力 50 / 感应 60 / 敏捷 40 |
| 骨灰 | 仿身泪滴（你的配装会同步给骨灰，务必穿好整套） |
| 护符 | 鲜血君王的欢愉 + 亚历山大碎片 + 义手剑士 + 腐败翼剑 |

思路：出血累积叠满后 Boss 血条瞬间蒸发，出招次数被压到最少，是最省时的打法。

## 四、二阶段：猩红腐败怎么应对

进二阶段瞬间会**炸一圈猩红腐败 AOE**，提前吃净化苔藓或拉开距离即可。二阶段她攻击更密集，但前摇更长——靠仿身泪滴拉住仇恨时大胆输出。P2 专属「幻影分身突刺」持续跑动 + 最后翻滚躲避即可。

> 一句话总结：女武神是**背板 Boss**——把水鸟乱舞三段时机练熟，配合出血流快速压血，稳过。

## 六、黄金树幽影 DLC 简介

- **发售**：**2024 年 6 月 21 日**（付费 DLC），独立地图「影之地」，难度更高。
- **进入门槛**：需先击败血王 Mohg、碎星 Radahn 后，在竞技场触碰茧/枯萎手臂进入（无需通关本体终 Boss）。
- **核心强度系统**：**幽影树碎片**——共 **50 个、20 级上限**，收集后在赐福点提升伤害/减伤；刚进 DLC 觉得难，先刷 **10–12 个碎片**难度立降。
- **推荐等级**：**120–150**，武器建议 +20 特殊 / +24 标准（据公开报道/第三方估算，来源 GameTruth 等）。
- 新增状态「孢子循环」「致盲」需对应护符/药剂解除；低 Guard Boost 格挡会被强制硬直，纯龟缩被惩罚。

## 常见问题 FAQ

**Q：玛莲妮亚 水鸟乱舞真的能无伤躲吗？**
A：能。口诀：「跳空跑远 → 一段外滚 → 二段前滚穿身 → 三段后滚脱离」。多背板几次即可稳定无伤。

**Q：打玛莲妮亚 用仿身泪滴还是黑刀狄希？**
A：用**仿身泪滴**。黑刀狄希会被持续击中，反而给玛莲妮亚回血，拖慢血线压制。

**Q：出血流 必须双剥尸曲剑吗？**
A：不必。尸山血海、艾琉诺拉双头刀同样可用，核心是「高出血累积 + 鲜血君王的欢愉」快速压血。

**Q：黄金树幽影 DLC 进不去怎么办？**
A：需先击败血王 Mohg 与碎星 Radahn。进 DLC 后优先收集 10–12 个幽影树碎片再推进。

**Q：Switch2 版和老版存档/内容互通吗？**
A：Tarnished Edition 含本体+DLC+新职业/护甲/马外观；老平台玩家买 Tarnished Pack（约 $4.99）即可获得新内容，具体跨平台存档据公开报道以任天堂/万代南梦宫公告为准。

**Q：新手先推主线还是先打玛莲妮亚？**
A：玛莲妮亚是隐藏 Boss（圣树底层），推荐等级 120–130，建议清完主线、等级碾压后再挑战。
