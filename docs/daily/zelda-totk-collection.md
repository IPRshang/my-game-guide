# 塞尔达传说：王国之泪 全收集向深度指南

《王国之泪》的"全收集"是一场横跨**地表、天空、地底**三层世界的马拉松——152 座神庙、900 个克洛格种子、27 种左纳乌装置，每一项都对应着实打实的战力提升（精力、容器、武器/盾/弓容量）。本篇把已拆散的黄金常青内容重新编排成一份"能照着刷"的路线图，数据全部沿用社区公认事实，力求搜索"神庙位置 / 克洛格 / 左纳乌装置"时一眼就能用上。

> 提醒：本指南零剧透，只讲机制与收集思路，不揭示主线区域名称。

## 一、152 座神庙：分布与解谜思路

全图共 **152 座神庙 = 120 座地面（Surface）+ 32 座天空（Sky）**。其中 **4 座在初始空岛**，是唯一强制完成的教程神庙，不打通无法离开空岛。

### 1.1 初始空岛四神庙（强制教程）

| 神庙 | 位置 | 解锁能力 |
|------|------|---------|
| Ukouh（乌可乌侯） | 初始空岛东 | 究极手（Ultrahand） |
| In-isa（因伊萨） | 初始空岛西 | 余料建造（Fuse） |
| Gutanbac（古坦巴奇） | 初始空岛北 | 通天术（Ascend） |
| Nachoyah（纳裘亚哈） | 初始空岛南 | 倒转乾坤（Recall） |

### 1.2 各区域神庙数量分布

### 1.3 神庙类型与解谜思路

- **解谜神庙**：常规谜题，核心是用好四大能力（究极手、余料建造、通天术、倒转乾坤）。卡关时优先想"能不能造个载具绕过去"。
- **劳鲁的祝福（Rauru's Blessing）**：进去就是奖励，内部仅一个宝箱，常见于需要复杂外部挑战或运送水晶任务完成后。
- **试炼场（Proving Grounds）⭐**：进入后所有装备被暂收，只发木棍/木弓/木盾 + 10 支箭，清光敌人后归还。代表如雷暴岛 Joku-usin（短路）、左纳乌锻造岛 Yansamin（低重力）、地面 Kamizun（初级）。

**解谜通用思路**：通天术穿顶登高、倒转乾坤"搭乘"落石上行、余料建造把高级素材融到基础武器提伤、究极手拼载具运水晶。**32 座天空神庙普遍需要载具**，建议精力充裕后再收尾。

> 每座神庙给 1 个祝福之光 + 1 个宝箱；**4 个祝福之光兑换 1 个心之容器或精力容器（1/5 圈）**。拔大师剑需 **2 圈精力（约 20 座神庙）**，所以中央海拉鲁 35 座（全区域最多、难度适中）建议优先清。

## 二、900 克洛格种子：分布与扩容技巧

克洛格种子（Korok Seeds）用于扩充**武器袋 / 弓箭袋 / 盾牌袋**容量，是"武器总坏"痛点的根本解法。

### 2.1 各区域数量

| 区域 | 数量 | 占比 | 收集难度 |
|------|:----:|:----:|:--------:|
| 地面（Surface） | **640** | 71% | ⭐⭐⭐ |
| 天空（Sky） | **160** | 18% | ⭐⭐⭐⭐ |
| 地下（Depths） | **100** | 11% | ⭐⭐⭐⭐⭐ |
| **总计** | **900** | 100% | |

### 2.2 容量扩容需求（关键数据）

| 容器 | 起始 → 满 | 所需种子 |
|------|-----------|:--------:|
| 武器袋 | 8 → **20 格** | **441 颗** |
| 弓箭袋 | 5 → 14 格 | 232 颗 |
| 盾牌袋 | 4 → 16 格 | 291 颗 |
| **全部拉满** | — | **964 颗**（实际仅 900，无法全满） |

> 结论：900 颗**不够**把三袋全满。优先级建议 **武器袋（441）> 盾牌袋（291）> 弓箭袋（232）**，毕竟武器最易碎。

### 2.3 谜题类型与解法速查

| 类型 | 解法要点 |
|------|----------|
| 石头堆 | 三堆中补回缺失那块 |
| 花朵 | 按顺序踩完全部 |
| 橡果 | 箭射树洞橡果 |
| 金属球 | 究极手放坑里 |
| 木桩 | 移到正确位置 |
| 蜡烛 | 点燃全部 |
| 风车 | 停止前射中所有靶心 |
| 漂浮方块 | 究极手拼出正确形状 |
| 落叶 / 苹果 | 烧落叶 / 摆正苹果 |
| 左纳乌装置（新增） | 装对应装置启动 |
| 洞窟入口（新增） | 解谜后入洞 |
| 天空岛 / 地底发光（新增） | 利用天空机制 / 黑暗中找发光点 |

**扩容技巧**：按地区逐个清理，每激活一个鸟望台就把周围克洛格收完；地面密度最高（中央海拉鲁 80、森林地区 70、费罗尼 70），优先地面再补天空与地底。

## 三、27 种左纳乌装置：四大类与最强蓝图

左纳乌装置（Zonai Devices）是王国之泪的核心创新，用**究极手**拼接成载具、桥梁、自动炮台。全游戏共 **27 种**，分四大类：

| 类别 | 数量 | 代表装置 |
|------|:----:|----------|
| 动力装置 | 6 | 风扇机、火箭、车轮、操纵杆、螺旋桨 |
| 武器装置 | 7 | 大炮、光线头、火龙头、冰冻头、电击头、追踪平台车、构造头 |
| 功能装置 | 9 | 弹簧、气球、浮空石、桩、便携锅、光源、镜等 |
| 特殊装置 | 5 | 翼、热气球、电池、不倒翁等 |
| **合计** | **27** | |

### 3.1 核心机制速记

- **构造头（Construct Head）**：让连接的武器装置自动瞄准最近敌人，是自动战斗机器的大脑。
- **风扇机**：能耗低、推力中，万能动力源。
- **火箭**：一次性极高推力（约 3 秒），盾牌贴火箭=举盾直接升空（火箭盾跳）。
- **操纵杆**：载具驾驶核心，须放重心位防偏航。

### 3.2 最强建造蓝图（照抄即用）

| 蓝图 | 材料 | 用途 |
|------|------|------|
| 🥇 悬浮摩托 | 风扇机 ×2 + 操纵杆 ×1 | 全游戏最实用载具，电耗极低，可飞到任意角落（约 9 矿成本） |
| 🥈 自动战斗机器人 | 构造头 ×1 + 光线头 ×2-3 | 全自动清怪，构造头自动瞄准 |
| 🥉 轰炸机 | 翼 ×1 + 风扇机 ×2 + 操纵杆 ×1 + 大炮 ×2 | 空中轰炸平台 |
| 直升机 | 风扇机 ×4（朝下）+ 操纵杆 ×1 | 垂直起降 |
| 全地形车 ATV | 大型车轮 ×4 + 车身 + 操纵杆 ×1 | 地底/陆地最强，爬坡抓地高 |

### 3.3 电池升级路线

电池容量从 **1 格（3 小格）** 升到 **满级 16 格（48 小格）**，共需约 **4500 结晶**，每格 100 结晶。

| 阶段 | 电池 | 推荐获取 |
|------|:----:|----------|
| 早期 1–4 格 | 地底采矿 + 佐纳乌冶炼厂（3 矿石→1 结晶） |
| 中期 4–8 格 | 讨伐地底 Boss（每个固定 20 结晶） |
| 后期 8–16 格 | 全面扫荡地底采矿洞窟 |

满级 16 格电池可让悬浮摩托**不间断飞行超 10 分钟**。**蓝图（Autobuild）** 在完成初始空岛后于地底"中央大废矿"解锁，存好经典设计一键复现。

## 四、三层世界收集路线规划

| 层级 | 关键收集 | 生存要点 |
|------|----------|----------|
| 地表（Surface） | 120 神庙 + 640 克洛格 + 鸟望台 | 主线推进顺手清，密度高 |
| 天空（Sky） | 32 神庙 + 160 克洛格 | 需载具建造能力，后期收尾 |
| 地底（Depths） | 100 克洛格 + 120 光明根（Lightroot）+ 左纳矿 | 瘴气掉心、靠光明花/光明根照明 |

**地底要点**：地表"深渊 Chasm"直通地底，下落开滑翔伞控落点避瘴气池；踩瘴气**永久减心上限**，只能靠**向阳花（Sundelion）料理**或站进已激活**光明根光环**恢复；地底 120 光明根与地表 120 神庙**一一镜像**，名字是神庙名倒序，顺路即可点亮+传送+回血。地底是电池结晶与强力装备（Bargainer 雕像换矿工服/装备）的主产地。

### 推荐推进顺序

1. **初始空岛**：4 强制神庙 + 拿滑翔伞 + 学四大能力。
2. **中央海拉鲁**：35 座神庙优先，攒精力拔大师剑；顺收地面克洛格。
3. **向外扩展**：赫布拉 → 拉聂尔 → 涅克卢达 → 格鲁德 → 埃尔丁 → 阿卡莱 → 法隆。
4. **地底扫荡**：采矿升电池、点亮光明根、收 100 克洛格。
5. **天空收尾**：32 神庙靠悬浮摩托/飞行器攻克。

> 想省心的玩家，先把"悬浮摩托"蓝图做出来——日常跑图效率直接翻倍，多数解谜可绕过硬刚。

## 常见问题 FAQ

**Q1：152 座神庙必须全做完吗？**
A：不是强制。但 4 个祝福之光换 1 个容器，全收可拉满精力/心；拔大师剑需约 20 座（2 圈精力）。

**Q2：900 克洛格能三袋全满吗？**
A：不能。全满需 964 颗，实际只有 900，建议优先武器袋（441）> 盾牌袋（291）> 弓箭袋（232）。

**Q3：27 种左纳乌装置都去哪拿？**
A：主要靠各地"左纳乌装置机"投放，天空岛与地底最密集；电池结晶靠地底采矿升级。

**Q4：地底太黑又掉心怎么办？**
A：用明亮花种（可绑箭射出）长期照明，瘴气损心靠向阳花料理或光明根光环恢复，普通食物无效。

**Q5：天空神庙找不到入口？**
A：先点亮对应区域鸟望塔，地图会显示天空群岛；32 座普遍需载具，建议精力充裕再挑战。

**Q6：王国之泪有 DLC 吗？**
A：官方未推付费 DLC（据公开报道/第三方估算，仅有免费修复补丁，最新 Ver. 1.4.3，2026-02）。
