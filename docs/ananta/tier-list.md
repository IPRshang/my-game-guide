# Ananta 角色强度榜（Tier List）

**Ananta（无限大）因「无角色抽卡」（网易未确认）而所有角色免费获取，意味着传统「抽不到强力角就没法玩」的压力被消解，tier list 的作用从「决定抽谁」变成了「了解谁适合什么玩法」。本篇是上线前的前瞻，具体强度以上线实战为准。**

## 为什么 Ananta 的 tier list 不一样

- 主流 gacha 开放世界（原神、鸣潮等）靠抽卡分角色强弱；Ananta 若真无角色抽卡，全员免费，tier list 不再决定「能不能获得」，只帮你选「玩什么风格」。
- 因此本榜更应看作「角色定位速览」而非「必抽清单」。

## 已知角色定位（前瞻）

> 以下基于公开演示与官方介绍整理，角色名与技能以上线为准。

- **Captain（队长）**：玩家化身，异常控制局（A.C.D.）成员，可切换多名可玩角色，承担主线与探索。
- **武术向角色**：以格斗连段 + 环境互动为核心，近战爆发高，适合喜欢贴脸输出的玩家。
- **元素 / 超自然向角色**：操控 Chaos 能力（火、雷等），适合控场与范围清理。
- **载具 / 移动向角色**：强化城市穿梭与载具战，适合探索流。

## 怎么用这份榜

- 先定自己喜欢的玩法（贴脸 / 控场 / 探索），再按定位挑角色，不必纠结「T0」。
- 上线后我们会依据实战数据更新为正式 tier list。

> 提醒：角色强度随版本平衡调整；任何上线前的「强度定论」都只是前瞻，请以官方与实战为准。
