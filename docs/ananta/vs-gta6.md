# Ananta 是抽卡游戏吗？和 GTA6 有什么区别？

> **变现口径说明**：「无角色抽卡、全角色免费、仅靠外观变现」来自日本媒体报道，**网易尚未官方确认**。商业化模型在上线前可能调整，请勿据此做出消费决策。详见 [Ananta 商业化：已确认 vs 传闻](/ananta/monetization)。
