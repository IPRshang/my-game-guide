# NTE 配队公式与 Esper Cycle 反应体系

**Neverness to Everness（异环 / NTE）** 的战斗核心不是「谁数值高」，而是 **Esper Cycle（异能循环）**——一套元素反应轮。配队先定反应、再选角色，比盲目堆战力强得多。这篇把配队公式拆透。

> 数据基于 NTE.wiki / lootbar / game8 等社区共识整理，角色名以国服「异环」译名为准，随版本可能变动。

## 一、Esper Cycle 反应轮

每个角色有元素属性，切换上场时若 Cycle 槽满，会按反应轮上**相邻元素**触发反应。反应分两层：

### 6 个基础反应
| 反应 | 元素组合 |
|---|---|
| Blossom | Anima + Lakshana |
| Remora | Lakshana + Cosmos |
| Nova | Cosmos + Psyche |
| Scorch | Incantation + Chaos |
| Stain | Psyche + Lakshana |
| Hexed | Cosmos + Anima |

### 2 个进阶反应（最强，应作为配队锚点）
- **Charge** = Remora + Blossom（大幅提升 Ultimate 能量循环）
- **Discord** = Scorch + Nova（破 Boss 韧性条最快）

### 6 大元素
Cosmos（宇宙）· Anima（生灵）· Incantation（咒文）· Chaos（混沌）· Psyche（灵能）· Lakshana（拉克珊娜）

## 二、四类定位与标准结构

一支队 **4 人**，功能要平衡：

| 定位 | 作用 | 代表 |
|---|---|---|
| **主 DPS** | 场上主要输出 | Nanally、Hotori、Jiuyuan、Baicang |
| **副 DPS** | 脱手伤害 / Cycle 充能 | Esper Zero、Mint、Hathor |
| **增益** | attack buff / 减抗 / 聚怪 | Sakiri、Haniel |
| **生存** | 治疗 / 护盾 / 伤害转移 | Fadia、Edgar、Adler |

**标准结构**：`1 主 DPS + 1 副 DPS + 1 增益 + 1 生存`
**激进结构**：`1 主 DPS + 2 副DPS/增益 + 1 灵活位`（冲 Charge/Discord 三连带）

> 关键：角色的**被动反应从替补位也生效**——所以即使 Nanally 不在场，她在队里就能翻倍某反应输出。配队前先看每个角色的被动反应。

## 三、主流配队模板

### 模板 1：Mono Blossom（顶尖，新手友好）
- 主 DPS **Nanally**（Anima）+ Cosmos 位 **Hotori** + Cycle 充能 **Esper Zero** + **Jiuyuan**（Anima 副 C）
- 逻辑：Zero 瞬满 Cycle + Hotori 技能复录，三倍触发 Blossom；Nanally 每次 Blossom 追加攻击，Jiuyuan 翻倍并抬上限。
- 预算替代：Hotori→Edgar（A 级 Cosmos），Jiuyuan→Mint（A 级 Anima）。

### 模板 2：Lacrimosa Scorch DoT（顶尖，打 Boss）
- 主 DPS **Lacrimosa** + DoT 增幅 **Sakiri**（Incantation）+ 破条 **Daffodill**（Chaos）+ 生存 **Fadia** / **Adler**
- 逻辑：叠最多 DoT 层数，Sakiri 按敌人身上 debuff 数放大 DoT，Adler 每次 Scorch 补随机 debuff。

### 模板 3：Daffodill Discord（破条机器）
- 主 DPS/破条 **Daffodill**（Chaos）+ **Sakiri**（Incantation，触发 Scorch）+ **Fadia**（Psyche，触发 Nova→Discord）+ 灵活 Incantation
- 逻辑：Discord 三连带把 Boss 韧性条啃得比谁都快。

### 模板 4：F2P 开荒队（零限定）
- **Esper Zero**（Cosmos，剧情白送）+ **Mint**（Anima，A 级易得）+ **Skia**（Lakshana，A 级）+ **Adler**（Incantation，A 级护盾）
- 逻辑：覆盖 Cosmos+Anima→Blossom、Lakshana+Cosmos→Remora、Charge 三连带，全免费角色。

## 四、配队 5 步公式

1. **先定 1–2 个反应**（优先 Charge 或 Discord），再看需要哪几个相邻元素。
2. 选主 DPS 锁定核心元素，补相邻元素角色触发反应。
3. 剩余位填**被动增幅同一反应**的角色（ bench 被动也算）。
4. 保持角色定位平衡（主 DPS + 副 DPS + 增益 + 生存）。
5. Beyond the Rails 高层需**两队**，提前养第二套反应。

## 五、常见疑问

**Q：没有 S 角色怎么配？**
A：A 级替代大多同元素、反应照样触发（见各模板预算替代）。Esper Zero 剧情白送，是万能 Cycle 充能件。

**Q：为什么我的伤害低？**
A：多半反应链断了——灵活位若是不同元素、打断相邻反应，收益直接掉档。保反应 > 保单卡强度。

**Q：需要专职奶吗？**
A：不一定。Adler/Fadia 用护盾/伤害转移就能扛，很多顶尖队不带奶。
