# NTE Iroi 配队与 Build 详解

Iroi 是《异环》（Neverness to Everness, NTE）1.3 版本登场的新角色。与同版本的 Shinku 相比，官方目前披露的关于 Iroi 的具体机制信息相对有限，因此本文不臆测她的技能数值，而是聚焦**1.3 抽卡与配队的通用原则**，并说明哪些细节需要在她正式上线后补全。

> 说明：关于 Iroi 的具体定位、属性与技能组，请以正式服上线后的官方情报为准；本文不虚构任何数值。

## 作为 1.3 新角色的定位

Iroi 是 1.3 版本的新增角色之一。在官方进一步公开她的技能组之前，我们建议把她当作"待揭晓的新卡"来对待：先观察她的属性归类、在队伍中的职责（输出 / 增益 / 生存），再决定培养优先级。

## 抽卡原则（1.3）

NTE 的卡池以"对免费玩家友好"著称，具体表现为：**没有 50/50 机制、保底清晰**。这意味着新角色（包括 Iroi）的获取相对可控，规划资源时压力小于许多同类产品。

- 若你资源有限，建议优先确认 Iroi 与你现有队伍的契合度，再决定是否投入。
- 更多抽卡机制与性价比分析见 [NTE 抽卡指南](/nte/gacha)。

## 配队通用原则

无论 Iroi 最终定位如何，配队都可遵循以下思路：

1. **明确主 C 与辅助分工**：先确定队伍的核心输出是谁，再把 Iroi 放在"补强短板"的位置。
2. **属性互补**：参考 [NTE 角色梯队](/nte/tier-list) 与 [NTE 配队思路](/nte/team-build)，让队伍覆盖更多机制。
3. **生存兜底**：任何新角色都应在有稳定生存保障的阵容中试用，避免盲目堆输出导致翻车。

## 上线后需要补全的信息

等 Iroi 正式上线后，你应优先确认：

- 她的属性与技能组定位；
- 她与 Shinku 等 1.3 角色的协同方式；
- 推荐的装备 / Arc 方向（参考 Arc Research Program 中的相关内容）。
