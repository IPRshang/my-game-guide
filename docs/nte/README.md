# NTE（Neverness to Everness）攻略中心

**Neverness to Everness（NTE）** 是 2026 年都市开放世界动作 RPG，于 **2026 年 4 月 29 日** 上线。设定在动漫风现代都市，融合开放世界探索、角色收集（gacha）与稳定的新卡池/兑换码节奏。

如果你搜的是 `NTE 兑换码`、`NTE 节奏榜` 或 `NTE 抽卡模拟器`，本中心就是为回答这些问题而建。

## 为什么值得做 NTE 攻略站

- **新游上线** —— 仍在首年内，大 wiki 覆盖不全。
- **抽卡驱动** —— 玩家持续规划抽取、找码、比对角色。
- **长线运营** —— 卡池、活动、兑换码轮换，站点有持续新鲜话题。

## 快速上手

1. 推 **教学** 解锁卡池与兑换入口。
2. 去 [兑换码页](./codes.md) 领可用码，过期不候。
3. 用 [节奏榜](./tier-list.md) 选首个目标角色。
4. 打开 [抽卡模拟器](./gacha.md) 规划保底与抽取的资源。

> 收藏本中心 —— 兑换码与节奏排名随每个版本更新。
