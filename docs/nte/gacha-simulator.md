# NTE 抽卡模拟器怎么用？

**NTE 抽卡模拟器可让你在不必消耗真实资源的情况下，模拟卡池概率、演练抽卡节奏、预判何时出 S 级角色，是规划养成资源的好工具。**

## 使用步骤

1. 进入本站 /nte/ 栏目的 **[交互式抽卡模拟器](/nte/gacha)**
2. 选择目标卡池（如当期 UP 的 S 级角色）
3. 设定模拟抽数，观察 S 级 / A 级出货分布与保底触发点
4. 结合 [新手攻略](/nte/beginner)，决定真实抽卡优先级

## 为什么先用模拟器

- **演练保底**：看清自己大概要抽多少才出目标 S 级，避免冲动清空货币。
- **对比卡池**：不同 UP 角色的期望抽数不同，模拟后能更理性地选池。
- **零成本试错**：不消耗任何真实资源，纯粹用于规划。

> 模拟器概率为社区估算的示意值，仅用于规划与娱乐，实际概率以游戏内公示为准。
