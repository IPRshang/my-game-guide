# NTE 崩溃 / 卡顿修复指南

《异环》（Neverness to Everness, NTE）最大的玩家痛点不是玩法，是**稳定性**——更新后 Unreal 崩溃、启动即闪退、开放世界卡成幻灯片，一度让不少人觉得 "unplayable"。这篇按**症状**给你一份可落地的自检清单，照着做基本能解决 90% 的性能问题。

> NTE 跑在 **Unreal Engine 5（Lumen）** 上，画面漂亮但对 CPU/GPU 极挑剔。先确认硬件：**最低 i7-10700 / GTX 1660 / 16GB；推荐 i7-12700 / RTX 3060 / 32GB**。低于 GTX 1660 会非常吃力。

## 一、通用前置（必做）

1. **必须装 SSD**，不要 HDD。城市资产实时流送，HDD 读写跟不上→贴图延迟、卡顿，画质调到最低也救不了。
2. **更新 GPU 驱动**（N 卡 / A 卡），UE5 首发版本驱动优化差距巨大。
3. **关后台程序**：NTE 吃 CPU 又吃内存，16GB 接近极限时，开个 Chrome + Discord 就爆。
4. **帧率上限设为显示器刷新率**（60 / 120 / 144），别无上限空转升温。
5. **全屏模式 > 无边框窗口**，UE5 下能降延迟、稳帧时间。

## 二、分症状速查

### 启动即崩溃 / 闪退
- 硬件是否达标（见上文）；低于 GTX 1660 极不稳。
- 更新驱动 + 装在 SSD + 关后台 + 启动器「修复游戏文件」。

### 游戏中反复崩溃
- 若是"服务器同步错误"类：换设备登录账号强制 resync，再回原设备。
- 反复崩→画质降一档 + 查 GPU 温度是否过热。
- **内存泄漏**（官方已知）：长时间游玩性能下降，整局重启即缓解，等后续补丁。

### 开放世界卡顿 / 掉帧
- **第一步降 View Distance（视距）到 Very Low**——对帧率影响最大。
- 仍卡→设置 → Others（第五标签，三个圆圈）→ 降 **Traffic（车流）** 密度，CPU 负担骤减。
- 战斗掉帧→降 Post-Processing 与 Global Illumination。
- 开 DLSS（RTX）/ FSR（AMD）Quality；低中端机开 Frame Generation。

### 贴图慢 / 加载慢
- 存储瓶颈：确认 SSD + 剩余空间 > 10%（满盘写入暴跌）。
- 纹理设 Low/Medium，减轻实时流送。

### 高延迟 / 网络卡
- NTE 有 4 服：**Asia / America / Europe / SEA**，选最近的。
- ⚠️ 服务器数据不互通，换服=开新号，慎重。
- 关 VPN / 代理，用有线网络。

## 三、推荐画质预设（按档位）

| 设置 | 低配 | 中配 | 高配 |
|---|---|---|---|
| 画质 | Performance | Balanced | Cinematic |
| 分辨率 | 1080p | 1080p / 原生 | 原生 |
| DLSS / FSR | 开 | 开 | 开 |
| 帧生成 | 开 | 开 | 关 |
| 视距 | Very Low | High | Ultra |
| 车流 | 低 | 中 | 高 |
| 动态模糊 | 关 | 关 | 关 |

> 低配机别不好意思：Performance + 低视距 + 低车流 + 30/45/60 帧封顶，照样能玩。

## 四、什么时候该等官方补丁
若以上全做完仍崩，且确认是内存泄漏 / 特定场景崩溃，多半是 Hotta Studio 侧问题，保持游戏更新即可。也可先到官方 Discord 反馈具体场景，帮官方复现。

## 五、1.3 已知问题

1.3 版本（国服 2026/8/12、全球服 2026/8/19）已知存在一些特定场景问题，遇到时可先尝试更新客户端：

- **时装店崩溃**：打开 Fashion Shop（时装商店）有时会导致游戏崩溃。
- **手柄问题**：
  - 在设备选择界面按 ○ 会错误地打开 Anomaly Pilgrimage（异象朝圣）界面；
  - Hotori（幌鸟）释放 Ultimate 后，她的基础攻击按钮可能消失；
  - Fight Club（格斗俱乐部）中，肥皂道具按钮可能不显示。
- **Shinku 动画异常**：在特定服装下可能出现动画 bug。

建议：保持客户端为最新版本，官方通常会通过后续补丁逐步修复上述问题。

## 常见问题

**Q：NTE 启动就崩溃 / 闪退怎么办？**
A：确认硬件达标（i7-10700 / GTX 1660 / 16GB）、更新 GPU 驱动、装在 SSD、关闭后台程序，并用启动器「修复游戏文件」。

**Q：NTE 开放世界卡顿怎么调？**
A：先把视距（View Distance）降到 Very Low，再降车流（Traffic）密度，并开启 DLSS（RTX）/ FSR（AMD）。

**Q：NTE 高延迟 / 网络卡怎么办？**
A：选离你最近的服务器（Asia / America / Europe / SEA），关闭 VPN / 代理，改用有线网络。
