# NTE Shinku 配队与 Build：宇宙 DPS 玩法详解

Shinku 是《异环》（Neverness to Everness, NTE）1.3 版本登场的新角色，定位为**宇宙（Cosmos）属性 DPS**。她的核心机制围绕"buff 管理"展开：她的终极技能会**消耗自身持有的独特增益**，以换取更高的伤害输出。换言之，Shinku 的爆发节奏取决于你能在释放 Ultimate 前堆叠并保留多少有效增益。

> 说明：以下内容基于当前已公开的情报整理，具体数值与连招细节以正式服上线后的实战为准。

## 核心机制理解

Shinku 的玩法可以用一句话概括：**先铺增益，再一次性兑现**。

- 她平时通过技能 / 普攻积累独特的自身增益；
- 这些增益不会无限保留，而是要在合适的窗口内用 Ultimate 消耗掉；
- 每消耗一层增益，Ultimate 的伤害随之提升。

因此，玩好 Shinku 的关键不是"越快放 Ultimate 越好"，而是"在增益叠满或接近满时再放 Ultimate"，避免浪费层数。

## 配队思路

基于她的宇宙 DPS 定位，配队应围绕"放大爆发窗口"与"提供增益 / 续航"两个方向：

1. **副 C / 增益位**：选择与 Shinku 属性互补、能在她 Ultimate 前帮忙铺场或提供增伤 Buff 的队友，让她的爆发更稳。
2. **生存 / 控制位**：宇宙 DPS 通常是脆皮输出，队伍里需要能扛伤或提供控制的角色，保证 Shinku 有安全的输出环境。
3. **破防 / 副输出**：补足对精英与 Boss 的削韧效率，缩短战斗时长。

具体角色搭配可结合 [NTE 角色梯队](/nte/tier-list) 与 [NTE 配队思路](/nte/team-build) 灵活调整。

## Build 方向

- **核心目标**：最大化 Ultimate 的增益消耗收益。优先提升与"终极技能伤害""增益相关收益"相关的词条与装备。
- **属性取舍**：在暴击、增伤与生存之间平衡——作为主 C，暴击 / 增伤收益通常更高，但也要保证不被秒杀。
- **操作习惯**：练习"攒满再放"的节奏，避免过早清空增益。

## 限定 Arc：Blushing Mirage

Shinku 的限定 Arc **「Blushing Mirage（绯红幻境）」**已加入 **Arc Research Program（弧光研究计划）**。如果你打算长期培养 Shinku，可以关注该 Arc 的获取与养成。

## 阵容示例（思路向）

- 生存：前排或控制型角色
- 灵活位：视副本机制补充破防或副输出
