# NTE（异环）新手开局做什么？

**NTE 新手开局先推主线解锁核心玩法，领齐预注册与登录奖励，用赠送的抽卡资源确定一名 S 级主力，再按每日/每周循环积累资源。**

## 开局步骤

1. 完成序章，熟悉都市探索、载具与「异常（Anomaly）」战斗
2. 领取全部预注册里程碑（含免费 S 级角色 Chiz、A 级 Aurelia）
3. 用赠送资源在卡池锁定 1 名 S 级主 C（如 Lacrimosa / Shinku）
4. 每日：清体力、签到、完成「猎人等级」与委托
5. 善用站内 **交互式抽卡模拟器** 规划资源，避免盲目抽卡

## 资源优先级

- **抽卡货币** —— 囤着；别每个卡池都花。
- **突破素材** —— 聚焦核心队，而非全阵容。
- **探索代币** —— 解锁地图奖励与进度。

> 别前期过度练级 —— 进度门槛比纯等级更重要。
