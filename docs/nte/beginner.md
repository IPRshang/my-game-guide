# NTE 新手攻略

刚玩 Neverness to Everness？这是高效的开服第一天路线。

## 开服清单

1. **做完教学** 解锁卡池与兑换入口。
2. 去 [兑换码页](./codes.md) **领兑换码** —— 免费素材前期很关键。
3. **探索初始城区** 熟悉位移与战斗手感。
4. 用 [节奏榜](./tier-list.md) 做指引，抽你的首个目标。

## 资源优先级

- **抽卡货币** —— 囤着；别每个卡池都花。
- **突破素材** —— 聚焦核心队，而非全阵容。
- **探索代币** —— 解锁地图奖励与进度。

## 技巧

- 用 [抽卡模拟器](./gacha.md) 在花资源前规划保底。
- 别前期过度练级 —— 进度门槛比纯等级更重要。
- 关注官方 Discord 的兑换码与活动节奏。

## 常见误区

- 没计划就抽（浪费货币）。
- 忽视探索奖励。
- 跳过邮件 / 兑换码。

## 下一步

- 看 [角色节奏榜](./tier-list.md) 决定抽谁。
- 用 [抽卡模拟器](./gacha.md) 模拟抽取。
