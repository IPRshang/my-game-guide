# NTE 兑换码 — 领取与兑换

兑换码是 NTE 里最快捷的免费提升。本页讲清 **兑换码在哪出现** 与 **怎么兑换**，并作为社区资源持续追踪可用码。

## 兑换码怎么用

1. 从主菜单打开 **设置**。
2. 找到 **兑换 / 兑换码** 选项。
3. 输入兑换码并确认。
4. 去游戏内 **邮件** 领取奖励。

> 兑换码通常 **限时** 且 **区分大小写**，尽快兑换。

## NTE 兑换码在哪发

- **官方 Discord** —— 活动与里程碑码主要发放点。
- **预约里程碑** —— 上线活动期间达成。
- **游戏内邮件** —— 部分奖励自动到账。
- **社媒活动** —— 官方 X（Twitter）与直播。
