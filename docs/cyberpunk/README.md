## 新手建议

1. **属性点洗不了！** 加点前想清楚方向
2. **街头声望很重要** — 影响商店物品和解锁任务
3. **多做支线** — 支线直接影响可用结局
4. **别急着推主线** — 华子等你多久都行
5. **义体是核心** — 螳螂刀、斯安威斯坦、网络接入仓，选一个发展方向
