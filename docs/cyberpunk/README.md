## 一、游戏背景简介

《赛博朋克 2077》由《巫师》系列开发商 CD Projekt RED 打造，背景设定在黑暗未来的 megalopolis「夜之城（Night City）」。玩家扮演雇佣兵 **V**，因一次任务失败被植入了传奇摇滚明星兼恐怖分子「强尼·银手（Johnny Silverhand）」的人格芯片，生命只剩倒计时——必须在有限时间内找到移除方法。

游戏改编自 1988 年的桌游《Cyberpunk》，充满反乌托邦、义体与黑客文化。经过 2023 年的 **2.0 版本大改** 与资料片 **往日之影**，口碑已从首发谷底逆袭为「最强开放世界 RPG 之一」。

> 本攻略默认**不剧透主线与结局走向**，仅提供机制与 Build 思路。

## 二、核心玩法机制说明

- **属性系统**：肉体（近战/血量）、反应（近战武器/枪械）、智力（黑客/快速破解）、镇定（潜行/冷血）、技术（制造/工程）。加点决定能装哪些义体与技能。
- **义体（Cyberware）**：替换身体部件获得能力，但受「义体容量」上限约束（2.0 后引入），需平衡。
- **快速破解（黑客）**：智力流核心，远程入侵敌人/摄像头，过热机制替代法力。
- **网络接入仓（Cyberdeck / 沙盒 / 操作系统）**：决定黑客流派，分控制/战斗/超频三类。
- **声望与街头声望**：完成任务提升，解锁商店与义体。
- **载具战斗与 AutoDrive**：2.3 更新加入自动驾驶（AutoDrive）与自驶出租车，城市通勤更顺。
- **分支对话与结局**：选择影响剧情与多结局（5+ 结局 + 隐藏结局），详见 [全结局](./endings)。
- **往日之影**：独立的谍战资料片剧情，新增狗镇区域与全新技能/义体，强烈推荐。

## 三、新手入门要点

1. **先推主线到解锁机制**：2.0 后大量系统随主线逐步开放，别一上来就乱点技能。
2. **选一个主流派起步**：黑客（智力）门槛最低、远程安全；独狼（肉体+反应）正面刚；忍者（反应+镇定）潜行暗杀。
3. **多用掩体与匍匐**：第一人称枪战靠掩体，别站桩输出。
4. **黑客流最友好**：早期「系统故障」「短路」等快速破解可无伤清场，适合手残。
5. **2.0 后建议开新档**：旧存档机制不同，重开能体验完整新版。
6. **常回公寓/义体医生**：升级义体、洗点（少量费用）都在医生处。
7. **买「终极版」含 DLC**：新玩家直接买 **Cyberpunk 2077: Ultimate Edition**（含往日之影），性价比最高。

## 四、进阶技巧与策略

- **Build 构筑**：黑客流堆「冷却+上传速度」；独狼堆「暴击+装甲」；忍者堆「近战伤害+暴击」。详见 [流派构筑](./builds)。
- **义体容量管理**：别贪多义体，留余量装关键部件（如「肾上腺转换器」「杀戮脉冲」）。
- **弱点与过载**：黑客可「上传病毒」连锁；独狼用「二段跳+滑铲」拉扯。
- **隐藏结局触发**：满足高强尼同步率 + 特定最终任务选择可解锁「单人攻楼」隐藏结局。
- **往日之影联动**：资料片新增「relic 技能树」，与本体 Build 互补，是终局最强成长线。
- **AutoDrive 妙用（2.3）**：长途赶路开自动驾驶，途中可做其他事；自驶出租车可快速移动。

## 五、常见问题解答（FAQ）

**Q1：现在还值得买吗？和首发比是同一款游戏吗？**
A：2.0 后已是**脱胎换骨**的版本，机制重做、Bug 大幅减少，口碑逆袭。新玩家直接买终极版即可。

**Q2：需要单独买往日之影吗？**
A：想要完整体验**强烈建议买**（终极版已含）。它是最终大型资料片，剧情与系统都顶级。

**Q3：能在 Switch 2 / Mac 上玩吗？**
A：能。2026 年《终极版》登陆 **Nintendo Switch 2** 与 **macOS（Apple 芯片）**，并支持跨平台云存档。

**Q4：PS5 Pro 有强化吗？**
A：有。2026 年 4 月免费更新加入光线追踪 Pro 模式与 PSSR 超分，三档画面模式可选。

**Q5：最新版本是多少？还有新内容吗？**
A：截至 2026 年，最新为 **2.3 + 2.31**。2.3 加入 AutoDrive、4 辆新载具、照片模式增强等；官方称 2.3 为最后大型内容更新，后续以技术与平台支持为主。续作 **Cyberpunk 2**（UE5）在预制作，预计 2028 年后。

**Q6：第一人称晕 3D 怎么办？**
A：开车/摩托时可切第三人称；设置里可调视野(FOV)与动态模糊缓解。
