# 《赛博朋克2077》专长指南

**在《赛博朋克2077》（2.0 及之后版本）中，专长由五大属性门控——肉体、反应、技术能力、智力和冷静。每升一级获得 1 个专长点，外加少量来自任务与技能进度的点数；你应当围绕 1~2 个属性来规划，而不是把点撒得太散。**

## 属性如何门控专长

| 属性 | 掌管 | 常见流派 |
|---|---|---|
| 肉体 | 霰弹枪、钝器、生命、义体容量 | 独狼 / 肉盾近战 |
| 反应 | 突击步枪、刀剑、机动 | 黑客枪混合 / 刺客 |
| 技术能力 | 制造、手雷、义体改装 | 科技武器专家 |
| 智力 | 快速破解、RAM、黑客 | 网络黑客 |
| 冷静 | 潜行、手枪、忍术 | 潜行手枪流 |

## 加点思路

1. **先定伤害来源**——单个武器类别或破解线。
2. **把对应属性推到 15~20**——多数强力专长在这个区间解锁。
3. **想要义体就点技术能力**——它同时门控制造与义体容量。
4. **肉体至少保持中等**——更多生命与义体容量对所有流派都有用。
5. **洗点很便宜**——重洗只需少量费用，大胆试错即可。

## 常见误区

- 把点平均撒在五个属性上（什么都解锁不了）。
- 忽视义体容量——它往往比一个专长带来的战力跃升更大。
- 过早猛点制造，手头还没材料可用。

## 常见问题

**Q：我能拿多少专长点？**
A：大约每级 1 点，外加技能进度与部分任务的额外点数——单周目不足以点满两棵以上的树。

**Q：可以洗点吗？**
A：可以。洗点付费即可，不必害怕早期试错。

**Q：第一周目点哪个属性最好？**
A：反应或肉体——两者都能直接提升生存与输出，不依赖复杂系统。
