# 赛博朋克2077 — 流派构筑指南

## 1. 黑客流（法爷）

**核心理念**：摄像头里瞪谁谁死

**加点**：智力 20 → 技术 20 → 镇定 15

**核心装备**：
- 网络接入仓：网监 5 型（终极）/ 瑞吉娜 4 型（前期）
- 快速破解：系统重置、义体过热、电磁短路、传染

**玩法**：接入摄像头 → 标记全部敌人 → 传染+过热 → 团灭，全程不进门

**评价**：★★★★★ 最安全、最安逸的流派。后期无敌。

## 2. 时停剑圣（版本之子）

**核心理念**：别人的子弹还没出膛，我的刀已经砍完了

**加点**：反应 20 → 技术 20 → 镇定 18

**核心装备**：
- 斯安威斯坦：千替 5 型（80% 时停，3 秒冷却）
- 武士刀：白虎 / 觉 / 手术刀
- 克伦齐科夫（闪避触发时停）

**玩法**：开时停 → 砍完 → 时停结束 → 一地尸体

**评价**：★★★★★ 帅 + 强 = 完美。

## 3. 枪械流（传统射手）

**加点**：反应 20 → 镇定 20 → 技术 15

**武器推荐**：
| 武器 | 类型 | 特色 |
|------|------|------|
| 应龙 | 冲锋枪 | 智能武器，自动锁头 |
| 大天使 | 手枪 | 暴击爆炸 |
| 突破 | 狙击枪 | 无视掩体穿墙 |
| 诗篇 11:6 | 突击步枪 | 燃烧弹 |

**评价**：★★★☆ 传统但有效。

## 4. 狂战士（莽夫）

**加点**：肉体 20 → 反应 15 → 技术 20

**核心**：狂战义体 + 大猩猩手臂 + 最高护甲

**玩法**：开狂暴 → 冲 → 锤。没有技巧，全是感情。

**评价**：★★★ 简单粗暴，适合不想动脑的玩家。
