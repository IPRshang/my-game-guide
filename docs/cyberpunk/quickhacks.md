# 《赛博朋克2077》快速破解指南

**快速破解是《赛博朋克2077》里类似法术的黑客能力：你透过扫描仪锁定敌人或设备，消耗 RAM，经过短暂上传时间后效果生效。网络黑客流派的核心，就是用廉价破解互相串联，并让它们在敌人之间扩散。**

## 核心机制

- **RAM** 是你的黑客资源；它会回复但有上限，上限由你的赛博deck 决定。
- **上传时间** 是破解施放后到生效的延迟——在正面交火中越短越好。
- **扩散** 让某些破解在击杀或触发后跳到附近敌人身上，这是黑客能滚雪球的关键。
- **排队** 让你能在破解结算前，对单一目标叠上好几个。

## 实用连招

1. **先控制**——上一个致瘫类破解（或迫使武器故障的那种），让敌人停火。
2. **再补伤害**——接上持续伤害类破解，在敌人被控时持续掉血。
3. **靠扩散**——一旦破解扩散，一次施放就能清掉一整间屋子。
4. **利用摄像头与设备**——黑进摄像头可以连锁到你根本看不见的敌人。

## 网络黑客养成

- 点 **智力**，换取 RAM 回复与破解威力。
- 升级你的 **赛博deck**——它决定 RAM 容量与可排队破解数量。
- 拿能 **缩短上传时间** 和 **击杀回 RAM** 的专长——它们把黑客从"慢"变成"碾压"。
- 留一把备用武器；有些敌人抗破解或免疫破解。

## 常见问题

**Q：网络黑客流派能不杀人通关吗？**
A：用致瘫与记忆清除类破解可以实现非致命通关，不过部分脚本化遭遇强制进入战斗。

**Q：为什么我的破解有时会失败？**
A：敌人可能抗性，或你 RAM 不足。在扫描仪里看目标的抗性。

**Q：该优先升级什么？**
A：赛博deck——它卡住 RAM 与排队数量，比任何单个破解都重要。
