# 赛博朋克2077 义体改造完全指南

义体（Cyberware）是赛博朋克2077的核心系统，直接决定了你的战斗风格和强度上限。2.0更新后义体系统大幅重做，本指南涵盖全部 10 个义体槽位的选择策略。

## 义体系统基础

### 义体容量（Cyberware Capacity）

你的身体只能承受有限量的义体改造：

| 属性 | 说明 |
|------|------|
| 容量上限 | 取决于等级和技术能力属性，可通过"义体容量芯片"永久提升 |
| 容量计算 | 每件义体有不同的容量占用值，不能超出总容量 |
| 超载惩罚 | 超出容量会导致持续掉血 |

### 护甲机制（2.0新版）

2.0版本后，护甲完全由 **表皮系统（Integumentary System）** 义体提供，服装不再提供护甲值。
