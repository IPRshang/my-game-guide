# Requisitos de sistema PC de Black Myth: Zhong Kui (estimación)

> ⚠️ Esta es una **hoja de especificaciones estimada**, no datos oficiales. Game Science no ha publicado los requisitos finales de Zhong Kui. Basado en el motor UE5, el gameplay del 20 ago y las necesidades de hardware de Black Myth: Wukong, sirve solo como referencia para comprar/actualizar PC — confirma con anuncios oficiales antes del lanzamiento.

## 1. ¿Por qué una estimación?

- Zhong Kui usa Unreal Engine 5 (UE5), mostrado en 21:9 ultrapanorámico con iluminación natural;
- Muchas escenas nubladas / con niebla presionan más la VRAM;
- Oficialmente sigue en desarrollo temprano; la optimización final no está decidida.

## 2. Mínimo (estimación)

| Elemento | Especificación estimada |
|---|---|
| SO | Windows 10 / 11 64-bit |
| CPU | 6 núcleos, p.ej. i5-8400 / R5 1600 |
| RAM | 16GB |
| GPU | GTX 1060 6GB / RX 580 8GB |
| Almacenamiento | 130GB SSD (HDD muy desaconsejado) |
| FPS esperados | 1080p bajo, 30–45 FPS con FSR/DLSS |

## 3. Recomendado (estimación)

| Elemento | Especificación estimada |
|---|---|
| SO | Windows 10 / 11 64-bit |
| CPU | i7-10700 / R7-5800X |
| RAM | 32GB (escenas grandes / niebla consumen RAM) |
| GPU | RTX 3060 / RTX 4060 / RX 6700 XT |
| Almacenamiento | 130GB SSD |
| FPS esperados | 1080p alto, 60 FPS |

## 4. 2K con ray tracing (estimación)

| Elemento | Especificación estimada |
|---|---|
| CPU | i7-13700 / R7-7700X |
| RAM | 32GB |
| GPU | RTX 4070 Ti / RX 7900 XT o superior |
| Almacenamiento | 130GB SSD |

## 5. Puntos que se pasan por alto

- **SSD obligatorio**: 130GB solo en SSD; el HDD causa tirones de carga o fallo al iniciar;
- **GPU depende de DLSS/FSR**: el mínimo necesita generación de fotogramas para mantener FPS;
- **Presión de RAM**: escenas con niebla / grandes consumen más; 32GB es el suelo recomendado;
- **Specs finales pendientes**: no son definitivas; los datos oficiales llegan antes del lanzamiento.
