# Guía de formación de equipo y Ciclo Esper de NTE

En **Neverness to Everness (NTE)**, el combate no va de "quién tiene el número más grande" — va del **Ciclo Esper**, una rueda de reacción elemental. Construye equipos reacción-primero, luego elige personajes, y superarás en daño a plantillas de fuerza bruta. Esta guía desglosa la fórmula.

> Cifras según consenso de comunidad NTE.wiki / lootbar / game8; los nombres de personajes pueden cambiar con parches.

## 1. La rueda de reacción Ciclo Esper

Cada personaje tiene un elemento. Entrar con el Medidor de Ciclo lleno dispara una reacción según los **elementos adyacentes** en la rueda. Dos niveles:

### 6 reacciones base
| Reacción | Elementos |
|---|---|
| Blossom | Anima + Lakshana |
| Remora | Lakshana + Cosmos |
| Nova | Cosmos + Psyche |
| Scorch | Incantation + Chaos |
| Stain | Psyche + Lakshana |
| Hexed | Cosmos + Anima |

### 2 reacciones avanzadas (las más fuertes — ancla tus builds en estas)
- **Charge** = Remora + Blossom (sobrecarga energía de Última)
- **Discord** = Scorch + Nova (rotura de jefe más rápida)

### Los 6 elementos
Cosmos · Anima · Incantation · Chaos · Psyche · Lakshana

## 2. Cuatro roles y estructura estándar

Un equipo son **4 personajes**, equilibrados por función:

| Rol | Trabajo | Ejemplos |
|---|---|---|
| **DPS principal** | daño en campo | Nanally, Hotori, Jiuyuan, Baicang |
| **Sub-DPS** | daño fuera de campo / gen Ciclo | Esper Zero, Mint, Hathor |
| **Buffer** | buff ATK / debuff / agrupación | Sakiri, Haniel |
| **Supervivencia** | cura / escudo / redirección | Fadia, Edgar, Adler |

**Estándar**: `1 DPS principal + 1 Sub-DPS + 1 Buffer + 1 Supervivencia`
**Agresivo**: `1 DPS principal + 2 Sub-DPS/Buffer + 1 Flexible` (persigue trío Charge/Discord)

> Clave: el **pasivo de reacción de un personaje funciona desde el banquillo** — Nanally duplica la salida de una reacción solo por estar en el equipo. Revisa el pasivo de reacción de cada personaje antes de construir.

## 3. Plantillas meta de equipo

### Plantilla 1: Mono Blossom (top, amigable para principiantes)
- DPS principal **Nanally** (Anima) + Cosmos **Hotori** + generador de Ciclo **Esper Zero** + **Jiuyuan** (sub Anima)
- Por qué: el llenado instantáneo de Ciclo de Zero + el replay de Habilidad de Hotori triples Blossom; Nanally añade golpes por Blossom, Jiuyuan duplica y sube tope.
- Presupuesto: Hotori→Edgar (A Cosmos), Jiuyuan→Mint (A Anima).

### Plantilla 2: Lacrimosa Scorch DoT (top, jefe)
- DPS principal **Lacrimosa** + amp DoT **Sakiri** (Incantation) + breaker **Daffodill** (Chaos) + Supervivencia **Fadia** / **Adler**
- Por qué: apila instancias DoT; Sakiri escala DoT por debuff de enemigo; Adler añade debuffs aleatorios en cada Scorch.

### Plantilla 3: Daffodill Discord (máquina de rotura)
- DPS/breaker principal **Daffodill** (Chaos) + **Sakiri** (Incantation→Scorch) + **Fadia** (Psyche→Nova→Discord) + flexible Incantation
- Por qué: el trío Discord mastica barras de aturdimiento de jefe más rápido que nada.

### Plantilla 4: Inicio F2P (sin limitados)
- **Esper Zero** (Cosmos, gratis de historia) + **Mint** (Anima, A) + **Skia** (Lakshana, A) + **Adler** (Incantation, A escudo)
- Por qué: cubre Cosmos+Anima→Blossom, Lakshana+Cosmos→Remora, trío Charge — todas unidades gratis.

## 4. La fórmula de equipo en 5 pasos

1. **Elige 1–2 reacciones primero** (prefiere Charge o Discord), luego ve qué elementos adyacentes necesitas.
2. Fija el elemento central de tu DPS principal; rellena elementos adyacentes para disparar reacciones.
3. Rellena huecos con personajes cuyos **pasivos amplifican la misma reacción** (los pasivos de banquillo cuentan).
4. Mantén equilibrio de roles (Principal + Sub + Buffer + Supervivencia).
5. Etapas tardías Beyond the Rails necesitan **dos equipos** — sube una segunda reacción pronto.

## Preguntas frecuentes

**Q: ¿Sin S-ranks?**
A: Los intercambios A-rank suelen ser del mismo elemento y las reacciones siguen disparándose (ver alts de presupuesto). Esper Zero es una unidad gratis de historia y un generador de Ciclo universal.

**Q: ¿Por qué es bajo mi daño?**
A: Probablemente una cadena de reacción rota — una elección flexible del elemento equivocado corta reacciones adyacentes y baja de nivel. Preserva la reacción > fuerza de carta única.

**Q: ¿Necesitas un curandero dedicado?**
A: No siempre. Adler/Fadia cubren defensa vía escudos/redirección; muchos equipos top no llevan curandero.
