# Elden Ring — Mejores builds

## 1. Sangrado (la respuesta de la versión)

**Atributos**: Vigor 50 / Arcano 60 / Destreza 40.

**Armas clave**:
- Espada de descuartizar (habilidad "Carnicería", acumulación de sangrado brutal)
- Doble Cuchilla de descuartizar (salto + 4 golpes; funden jefes)
- Espada doble de Eleonora

**Amuletos**: Regocijo del Rey Sangriento + Fragmento de Alexander + Espada de mano de prótesis + Ala de podredumbre.

**Valoración**: fuerte desde la 1.0 hasta la última versión; la única build divina.

## 2. Mago (a distancia, cómodo)

**Atributos**: Inteligencia 80 / Concentración 40 / Vigor 40.

**Equipo clave**:
- Vara de cristal de Lusat / Cetro de Caria
- Hoja de luna de Adula + Cometa de Azur + Cometa nocturna

**Amuletos**: Escorpión mágico + Retrato de Godfrey + Estatua de Radagon + Colgante de ámbar azul +2.

**Elixir**: Lágrima de revelado mágico + lágrima de azul infinito.

**Combo**: elixir de azul infinito → Corriente del alma (Cometa de Azur) → evaporas al jefe con un botón.

## 3. Espada gigante (el romance de los hombres)

**Atributos**: Fuerza 66 (a dos manos equivale a 99) / Resistencia 40.

**Armas clave**:
- Espada gigante (habilidad "Tajo de león")
- Gran alabarda martillo (habilidad "Golpe de oración")

**Amuletos**: Gran jarrón de armas + Gran escudo de emblema dragón + Amuleto de hacha + Tortuga verde.

**Estilo**: Tajo de león → ejecución → Tajo de león → ejecución ...

## 4. Guerrero de fe (todoterreno)

**Atributos**: Fe 60 / Fuerza 40 / Vigor 40.

**Equipo clave**:
- Hoja profanada (robas vida al matar; motor de empuje infinito)
- Gran espada de cazar deidades (daño de negro fuego)

**Oraciones**: Juramento del Árbol Áureo + Fuego otorga fuerza + Refugio de negro fuego + Rayo de dragón antiguo.

**Valoración**: build perfecta y completa; golpea, cura y buffea.

## Preguntas frecuentes

**Q: ¿Cuál es el mejor build para empezar?** A: Sangrado. Funciona desde el inicio y es la build más fiable contra jefes duros como Malenia.

**Q: ¿Mago o fe?** A: Mago es más cómodo a distancia; fe es más versátil (cura + buff + daño). Elige según tu estilo.

**Q: ¿Vale la pena la espada gigante?** A: Sí para quien disfrute el ritmo lento y los ejecuciones; el Tajo de león es muy satisfactorio, pero exige cuerpo a cuerpo.
