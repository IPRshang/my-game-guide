# Requisitos de sistema de PC de Ananta (mín / recomendado)

Las specs de abajo son de la **prueba cerrada CBT1 de enero de 2026**; la build final de lanzamiento puede diferir.

## Comparación de specs

| | Mínimo | Recomendado |
|---|---|---|
| SO | Windows 10 / 11 64-bit | Windows 10 / 11 64-bit |
| CPU | Intel i5-9400F o AMD Ryzen 7 3700X | Intel i7-12700K o AMD Ryzen 9 9900X |
| GPU | NVIDIA GTX 1060 6GB (o equivalente AMD) | NVIDIA RTX 3080 (8GB VRAM) |
| RAM | 16 GB | 32 GB |
| Almacenamiento | SSD (~46GB build CBT1) | 60 GB SSD |

## Funciones gráficas confirmadas

- **DLSS 4 Multi Frame Generation** — confirmado por NVIDIA
- **Reflejos con Ray-Tracing** — confirmado
- **Mando DualSense PS5** — compatible en PC

## ¿Puede un portátil mover Ananta?

La CBT1 requirió **SSD y GPU discreta**. Tramos aproximados:

- **Entrada:** dGPU clase GTX 1060 6GB + 16GB RAM — jugable a 1080p bajo;
- **Fluido:** RTX 3060 / 3070 — estables 60 fps a medio-alto;
- **Alta calidad:** RTX 3080+ con DLSS 4 para mejores resultados.

## Consejos de optimización

1. Usa un **SSD** — la CBT1 lo requirió; los HDD detienen la carga;
2. Activa **DLSS 4** para equilibrar fps y visuales;
3. Si la VRAM aprieta, baja "Reflejos con Ray-Tracing" primero;
4. Cierra apps en segundo plano que consuman memoria de GPU (navegadores, herramientas de captura).

## Preguntas frecuentes

**Q: ¿Cuánto almacenamiento necesita Ananta?**
A: ~46GB para la build CBT1; reserva 60GB SSD para el lanzamiento.

**Q: ¿Soporta AMD FSR?**
A: Solo DLSS 4 (NVIDIA) está confirmado por ahora; FSR no está confirmado. Las GPU AMD corren a medio-bajo nativo.

**Q: ¿Pueden jugar los Mac?**
A: Las plataformas confirmadas son PC / PS5 / iOS / Android; Mac no aparece.

**Q: ¿Estará en Steam?**
A: PC usa el launcher propio de NetEase; Steam / Epic aún no se han anunciado.
