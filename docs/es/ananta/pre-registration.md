# Guía de prerregistro de Ananta

## Dónde prerregistrarse

Sitio oficial: **anantagame.com** (el prerregistro global abrió el 5 de diciembre de 2024).

A mayo de 2026, Ananta supera los **17 millones** de prerregistros globales.

## Paso a paso por plataforma

- **PC (launcher de NetEase):** Visita el sitio → haz clic en "Pre-Register" → vincula correo / teléfono;
- **PlayStation 5:** Vía la página de PS Store o redirigido desde el sitio oficial;
- **iOS / Android:** Busca "Ananta" en la App Store / Google Play, o usa la redirección del sitio.

## Recompensas de prerregistro

Para ser claros: **hasta donde se sabe, NetEase no ha publicado tiers de recompensa por hitos específicos** — el formulario de prerregistro no tiene regalos por niveles por ahora. Vigila los canales oficiales tras inscribirte; las ventajas de lanzamiento suelen aparecer con las pruebas / el lanzamiento.

## ¿Por qué molestarse en prerregistrarse?

- Recibe el primer aviso de apertura de servidores, acceso a pruebas y eventos de lanzamiento;
- Algunos juegos desbloquean recompensas para todos en hitos de prerregistro (Ananta no tiene ninguno confirmado aún, pero vale la pena vigilarlo);
- Es gratis y no afecta las probabilidades del sorteo de pruebas posteriores (p. ej. CBT).

## Preguntas frecuentes

**Q: ¿Cuesta dinero el prerregistro?**
A: No, es completamente gratis.

**Q: ¿El prerregistro se relaciona con el acceso a la beta cerrada (CBT)?**
A: La CBT1 invitó jugadores vía prerregistro oficial + selección de NetEase; el prerregistro es un punto de entrada para pruebas posteriores.

**Q: ¿Progreso entre dispositivos / plataformas?**
A: El cross-play y la progresión cruzada se reportan ampliamente pero aún no se detallan formalmente; usa una cuenta de NetEase.

**Q: ¿Cuándo se lanza Ananta?**
A: Oficialmente previsto para 2026, fecha exacta sin confirmar; JPMorgan sugiere un posible deslizamiento a 1H 2027. Mira la [Guía de Ananta](./).
