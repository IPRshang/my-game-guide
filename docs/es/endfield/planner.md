# Planificador de base de Endfield

Usa esta herramienta interactiva para planificar la distribución de tu fábrica antes de construir. Ajusta la
cantidad de cada edificio y observa los totales actualizarse en vivo.

<EndfieldPlanner />

## Cómo leerlo

- **Energía total** debe mantenerse en 0 o por encima. Si baja a negativo, añade Reactores o recorta
  edificios que consumen mucha energía.
- **Población total** muestra cuántos operadores emplea tu base — útil para planificar asignaciones logísticas.
- **Producción** es un recordatorio rápido de lo que aporta cada edificio.

## Consejos

- Coloca siempre **Reactores** primero en tu base real.
- Empareja **Talleres** con suficientes operadores logísticos que generen **Población**.
- Revísalo tras cada parche de versión, ya que las estadísticas de edificios cambian.

> Los números aquí son puntos de partida ilustrativos. Sustitúyelos por valores del juego conforme
> aprendas las estadísticas exactas.

## Preguntas frecuentes

**Q: ¿Cómo uso el Planificador de base de Endfield?**
A: Ajusta la cantidad de cada edificio y observa energía total, población y producción actualizarse en vivo; mantén la energía total en 0 o más para evitar un déficit.
