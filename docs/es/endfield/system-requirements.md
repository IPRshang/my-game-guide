# Requisitos de sistema de Arknights: Endfield (2026)

Arknights: Endfield se lanzó en todo el mundo el **22 de enero de 2026** en **PS5, PC, Android, iOS y la Epic Games Store**, con guardado multiplataforma. Aquí tienes las especificaciones **mínimas** y **recomendadas** por plataforma para saber si tu dispositivo lo moverá con fluidez — y si merece la pena mejorar el PC.

## Resumen por plataforma

| Plataforma | Estado | Notas |
|----------|--------|-------|
| PC (Windows) | Disponible | Vía launcher de Hypergryph / Epic |
| PlayStation 5 | Disponible | Guardado cruzado |
| Android | Disponible | Soporte parcial de HarmonyOS |
| iOS / iPadOS | Disponible | iPhone XS / A12 en adelante |
| Epic Games Store | Disponible | Entrada alternativa de PC |

## Requisitos de sistema para PC

| Componente | Mínimo | Recomendado |
|-----------|---------|-------------|
| SO | Windows 10 64-bit / Windows 11 64-bit | Igual |
| DirectX | 11.1 o superior | Igual |
| CPU | Intel Core i5-9400F o equivalente | Intel Core i7-10700K o equivalente |
| GPU | NVIDIA GeForce GTX 1060 o equivalente | NVIDIA GeForce RTX 2060 o equivalente |
| RAM | 16 GB | 16 GB o más |
| Almacenamiento | 50 GB+ libres (40 GB extra al extraer) | Instala en SSD |

> **Consejo de SSD**: la editora recomienda explícitamente un SSD. La extracción necesita temporalmente ~40 GB extra, así que deja margen.

## Especificaciones móviles y de consola

- **Android**: Android 10.0+; mínimo Snapdragon 855 / Dimensity 1000 / Kirin 990, recomendado Snapdragon 8+ Gen1 / Dimensity 9000 / Kirin 9000S; RAM 6 GB mín / 8 GB rec; 25 GB+ almacenamiento.
- **iOS / iPadOS**: iOS 15.0 / iPadOS 15.0+; mínimo iPhone XS / A12, recomendado iPhone 13 Pro / A15; RAM 4 GB mín / 6 GB rec; 25 GB+ almacenamiento.
- **PS5**: 60 GB+ almacenamiento.

## Preguntas frecuentes

**Q: ¿Cuánto espacio en disco necesita Endfield?**
A: Al menos 50 GB en PC, con ~40 GB extra necesarios temporalmente durante la extracción. Instala en SSD y mantén ~90 GB libres por seguridad.

**Q: ¿Puede moverlo una GTX 1060?**
A: Sí — es la GPU mínima oficial. Espera ajustes bajos; para una experiencia más fluida mira la spec recomendada (RTX 2060 en adelante).

**Q: ¿Hay versión para Mac?**
A: Las plataformas anunciadas oficialmente son PC (Windows), PS5, Android, iOS y Epic. No se ha anunciado versión macOS.

**Q: ¿El progreso pasa entre dispositivos?**
A: Sí. La misma cuenta sincroniza entre plataformas bajo un mismo UID.
