# Black Myth: Wukong — Curios y Soaks (colección)

> 48 curios + 24 soaks + pociones | cómo conseguirlos y combinarlos

## Sistema de curios

Los curios son un sistema central; equipas hasta **3 a la vez** para bonus pasivos.

| Tipo | Cantidad | Cómo conseguir |
|------|:--:|----------------|
| Ataque | 12 | jefes / tienda |
| Defensa | 10 | cofres / zonas ocultas |
| Función | 14 | misiones / exploración |
| Raro | 12 | jefes ocultos / final verdadero |
| **Total** | **48** | |

> Principio: elige el curio núcleo de tu build → complementa supervivencia → ajusta función según necesidad.

## Soaks (24 tipos)

Mejora atributos de forma permanente; cada uno se usa una vez.

| Clase | Ejemplos | Efecto |
|-------|----------|--------|
| Vida | ginseng (+50), loto de nieve (+150) | + vida máxima |
| Aguante | goji (+20), cordyceps (+40) | + aguante |
| Ataque | hueso de tigre (+5), cuerno de dragón (+15) | + ataque |
| Defensa | caparazón (+5), arena diamante (+8 %) | + defensa |
| Especial | melocotón (+5 todo), hierba lunar (10 % noche) | varios |

- **Thrust**: Anillo de embestida + Colgante de combo + Anillo de esquiva

## Preguntas frecuentes

**Q: ¿Cuántos curios puedo equipar?** A: Hasta 3 a la vez. Elige el núcleo de tu build y complementa con supervivencia.

**Q: ¿Los soaks son permanentes?** A: Sí, cada soak se aplica una vez y mejora el atributo para siempre; no desaparece.

**Q: ¿Qué curio consigo primero?** A: La Calabaza mágica (tienda del anciano) y el Sello ojo de fuego valen para casi todos los estilos.
