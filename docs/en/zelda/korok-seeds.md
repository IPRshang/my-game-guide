## 🎯 Korok Puzzle Types

### Common Types
| Type | Description | Solution |
|------|-------------|----------|
| **Rock Piles** | Three rock piles, one is missing a rock | Place the missing rock |
| **Flowers** | One flower, more appear when stepped on | Step on all flowers in order |
| **Acorns** | Acorn in a tree hollow | Shoot the acorn with an arrow |
| **Metal Balls** | Big hole with a metal ball nearby | Use Ultrahand to put ball in hole |
| **Tree Stumps** | Stumps in wrong positions | Move stumps to correct spots |
| **Candles** | Row of candles, some unlit | Light all candles |
| **Pinwheels** | Pinwheel with targets nearby | Shoot all targets before it stops |
| **Floating Blocks** | Blocks floating in air | Use Ultrahand to form correct shape |
| **Leaves** | Leaf pile under a tree | Burn the leaf pile |
| **Apples** | Apples on tree, one in wrong spot | Rearrange apples to correct positions |

### New Types (TotK Exclusive)
| Type | Description | Solution |
|------|-------------|----------|
| **Zonai Devices** | Requires Zonai device to trigger | Install device and activate |
| **Cave Entrances** | Puzzle at cave entrance | Solve to enter cave |
| **Sky Islands** | Special puzzles on sky islands | Use sky island mechanics |
| **Glowing Depths** | Near glowing seeds underground | Find glowing spots in darkness |

## 💡 Efficient Collection Tips

### 1. Systematic Collection by Region
```
Unlock Skyview Tower → Mark all Koroks in area → Collect one by one → Next area
```

### 2. Use Map Markers
- Use different colored pins for different Korok types
- Delete or check off collected ones
- Recommended to use interactive map for assistance

### 3. Essential Items
| Item | Purpose |
|------|---------|
| **Brightbloom Seeds** | Depths lighting essential |
| **Rockets** | Quick launch to sky islands |
| **Bow + Lots of Arrows** | Shoot acorns / targets / candles |
| **Fire Fruit / Fire Rod** | Light candles / burn leaves |
| **Ultrahand** | Move rocks / metal balls / blocks |
| **Ascend** | Quick return from depths to surface |

### 4. Expansion Priority
1. **Weapon slots** (highest priority) — weapons break fastest
2. **Shield slots** (second) — shields also break often
3. **Bow slots** (last) — bows are relatively sufficient

## 🔍 Hard-to-Find Korok Locations

### Easy to Miss Spots
1. **Inside buildings** — ruins / caves / wells
2. **Tree tops** — need to climb or fly up
3. **Behind waterfalls** — many hidden behind falls
4. **Small islands** — in lakes / ocean
5. **Cliff edges** — search along cliffs
6. **Deep Depths** — deepest corners underground

### Search Tips
- If you hear the "Korok sound", one is nearby
- Look for unnatural things (rock piles, lone flowers)
- Scan with the telescope
- High vantage points make them easier to spot
