## Core Mechanic: Fuse

Tears of the Kingdom's signature feature — nearly any item can be fused via "Fuse":

| Base | Recommended Fuse | Effect |
|------|------------------|--------|
| Master Sword | Silver Lynel Horn | +55 ATK, extremely sharp |
| Zora Spear | Ice Keese Wing | Double damage when wet + freeze |
| Gerudo Scimitar | Silver Lynel Horn | High durability + massive damage |
| Royal Guard's Shield | Cannon | Shield parry = long-range artillery |
| Rocket Shield | Rocket | Shield jump = instant liftoff |

---

> **Pro Tip**: Don't rely on combat alone — use **Ultrahand** and **Autobuild** to construct vehicles, bridges, and aircraft. Many puzzles can be completely bypassed.
