# Ananta PC System Requirements (Min / Recommended)

Specs below are from the **January 2026 China CBT1 closed test**; the final launch build may differ.

## Spec Comparison

| | Minimum | Recommended |
|---|---|---|
| OS | Windows 10 / 11 64-bit | Windows 10 / 11 64-bit |
| CPU | Intel i5-9400F or AMD Ryzen 7 3700X | Intel i7-12700K or AMD Ryzen 9 9900X |
| GPU | NVIDIA GTX 1060 6GB (or equivalent AMD) | NVIDIA RTX 3080 (8GB VRAM) |
| RAM | 16 GB | 32 GB |
| Storage | SSD (~46GB CBT1 build) | 60 GB SSD |

## Confirmed Graphics Features

- **DLSS 4 Multi Frame Generation** — confirmed by NVIDIA
- **Ray-Traced Reflections** — confirmed
- **DualSense PS5 controller** — supported on PC

## Can a Laptop Run Ananta?

CBT1 required an **SSD and a discrete GPU**. Rough tiers:

- **Entry:** GTX 1060 6GB-class dGPU + 16GB RAM — playable at 1080p low;
- **Smooth:** RTX 3060 / 3070 — stable 60 fps at medium-high;
- **High quality:** RTX 3080+ with DLSS 4 for best results.

## Optimization Tips

1. Use an **SSD** — CBT1 required it; HDDs stall loading;
2. Enable **DLSS 4** to balance fps and visuals;
3. If VRAM is tight, lower "Ray-Traced Reflections" first;
4. Close background apps that eat GPU memory (browsers, capture tools).

## FAQ

**Q: How much storage does Ananta need?**
A: ~46GB for the CBT1 build; reserve 60GB SSD for launch.

**Q: Does it support AMD FSR?**
A: Only DLSS 4 (NVIDIA) is confirmed so far; FSR is unconfirmed. AMD GPUs run at native medium-low.

**Q: Can Macs play it?**
A: Confirmed platforms are PC / PS5 / iOS / Android; Mac is not listed.

**Q: Will it be on Steam?**
A: PC uses NetEase's own launcher; Steam / Epic are not yet announced.
