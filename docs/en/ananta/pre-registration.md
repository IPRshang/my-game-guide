# Ananta Pre-Registration Guide

## Where to Pre-Register

Official site: **anantagame.com** (global pre-registration opened December 5, 2024).

As of May 2026, Ananta has passed **17 million** global pre-registrations.

## Step-by-Step by Platform

- **PC (NetEase launcher):** Visit the site → click "Pre-Register" → bind email / phone;
- **PlayStation 5:** Via the PS Store page or redirected from the official site;
- **iOS / Android:** Search "Ananta" on the App Store / Google Play, or use the site redirect.

## Pre-Registration Rewards

To be upfront: **as of this writing, NetEase has not published specific milestone reward tiers** — the pre-registration form currently has no tiered giveaways. Watch official channels after signing up; launch perks typically drop with tests / release.

## Why Bother Pre-Registering?

- Get first notice of server opening, test access, and launch events;
- Some games unlock all-player rewards at pre-reg milestones (Ananta has none confirmed yet, but worth watching);
- It's free, and doesn't affect later test lottery odds (e.g., CBT).

## FAQ

**Q: Does pre-registration cost money?**
A: No, it's completely free.

**Q: Does pre-registration relate to closed beta (CBT) access?**
A: CBT1 invited China-region players via official pre-registration + NetEase selection; pre-reg is one entry point for later tests.

**Q: Cross-device / cross-platform progress?**
A: Cross-play and cross-progression are widely reported but not yet formally itemized; use one NetEase account.

**Q: When does Ananta release?**
A: Officially targeted for 2026, exact date unconfirmed; JPMorgan suggests a possible slip to 1H 2027. See [Ananta Game Guide](./).
