# Black Myth: Zhong Kui PC System Requirements (Estimate)

> ⚠️ This is an **estimated spec sheet**, not official data. Game Science has not published Zhong Kui's final requirements. Based on the UE5 engine, the Aug 20 gameplay footage, and Black Myth: Wukong's hardware needs, this is for PC-buying / upgrade reference only — confirm with official announcements before launch.

## 1. Why Estimate?

- Zhong Kui runs on Unreal Engine 5 (UE5), shown in 21:9 ultrawide with natural lighting;
- Lots of overcast / foggy scenes put more pressure on VRAM;
- Officially still early in development; final optimization undecided.

## 2. Minimum (Estimate)

| Item | Estimated spec |
|---|---|
| OS | Windows 10 / 11 64-bit |
| CPU | 6-core, e.g. i5-8400 / R5 1600 |
| RAM | 16GB |
| GPU | GTX 1060 6GB / RX 580 8GB |
| Storage | 130GB SSD (HDD strongly discouraged) |
| Expected FPS | 1080p low, 30–45 FPS with FSR/DLSS |

## 3. Recommended (Estimate)

| Item | Estimated spec |
|---|---|
| OS | Windows 10 / 11 64-bit |
| CPU | i7-10700 / R7-5800X |
| RAM | 32GB (big scenes / fog eat memory) |
| GPU | RTX 3060 / RTX 4060 / RX 6700 XT |
| Storage | 130GB SSD |
| Expected FPS | 1080p high, 60 FPS |

## 4. 2K Ray-Tracing (Estimate)

| Item | Estimated spec |
|---|---|
| CPU | i7-13700 / R7-7700X |
| RAM | 32GB |
| GPU | RTX 4070 Ti / RX 7900 XT or above |
| Storage | 130GB SSD |

## 5. Easy-to-Miss Points

- **SSD required**: 130GB on SSD only; HDD causes load stutter or failure to launch;
- **GPU relies on DLSS/FSR**: minimum spec needs frame generation to hold framerate;
- **Memory pressure**: foggy / large scenes consume more RAM; 32GB is the recommended floor;
- **Final specs pending**: not final; official accurate data arrives pre-launch.
