# NTE Team Building & Esper Cycle Guide

In **Neverness to Everness (NTE)**, combat isn't about "who has the biggest number" — it's the **Esper Cycle**, an elemental reaction wheel. Build teams reaction-first, then pick characters, and you'll out-damage brute-force rosters. This guide breaks the formula down.

> Figures from NTE.wiki / lootbar / game8 community consensus; character names may shift with patches.

## 1. The Esper Cycle Reaction Wheel

Each character has an element. Swapping in with a full Cycle Gauge triggers a reaction based on **adjacent elements** on the wheel. Two tiers:

### 6 base reactions
| Reaction | Elements |
|---|---|
| Blossom | Anima + Lakshana |
| Remora | Lakshana + Cosmos |
| Nova | Cosmos + Psyche |
| Scorch | Incantation + Chaos |
| Stain | Psyche + Lakshana |
| Hexed | Cosmos + Anima |

### 2 advanced reactions (strongest — anchor your builds on these)
- **Charge** = Remora + Blossom (supercharges Ultimate energy)
- **Discord** = Scorch + Nova (fastest boss break)

### The 6 elements
Cosmos · Anima · Incantation · Chaos · Psyche · Lakshana

## 2. Four Roles & Standard Structure

A team is **4 characters**, balanced by function:

| Role | Job | Examples |
|---|---|---|
| **Main DPS** | on-field damage | Nanally, Hotori, Jiuyuan, Baicang |
| **Sub-DPS** | off-field dmg / Cycle gen | Esper Zero, Mint, Hathor |
| **Buffer** | ATK buff / debuff / grouping | Sakiri, Haniel |
| **Survival** | heal / shield / redirect | Fadia, Edgar, Adler |

**Standard**: `1 Main DPS + 1 Sub-DPS + 1 Buffer + 1 Survival`
**Aggressive**: `1 Main DPS + 2 Sub-DPS/Buffer + 1 Flex` (chase Charge/Discord trio)

> Key: a character's **reaction passive works from the bench** — Nanally doubles a reaction's output just by being on the squad. Check each char's passive reaction before building.

## 3. Meta Team Templates

### Template 1: Mono Blossom (top-tier, beginner-friendly)
- Main DPS **Nanally** (Anima) + Cosmos **Hotori** + Cycle enabler **Esper Zero** + **Jiuyuan** (Anima sub)
- Why: Zero's instant Cycle fill + Hotori's Skill replay triple Blossom procs; Nanally adds hits per Blossom, Jiuyuan doubles & raises cap.
- Budget: Hotori→Edgar (A Cosmos), Jiuyuan→Mint (A Anima).

### Template 2: Lacrimosa Scorch DoT (top-tier, boss)
- Main DPS **Lacrimosa** + DoT amp **Sakiri** (Incantation) + breaker **Daffodill** (Chaos) + Survival **Fadia** / **Adler**
- Why: stack DoT instances; Sakiri scales DoT per enemy debuff; Adler adds random debuffs on every Scorch.

### Template 3: Daffodill Discord (break machine)
- Main DPS/breaker **Daffodill** (Chaos) + **Sakiri** (Incantation→Scorch) + **Fadia** (Psyche→Nova→Discord) + flex Incantation
- Why: Discord trio chews boss stagger bars faster than anything.

### Template 4: F2P Starter (no limited)
- **Esper Zero** (Cosmos, free from story) + **Mint** (Anima, A) + **Skia** (Lakshana, A) + **Adler** (Incantation, A shield)
- Why: covers Cosmos+Anima→Blossom, Lakshana+Cosmos→Remora, Charge trio — all free units.

## 4. The 5-Step Team Formula

1. **Pick 1–2 reactions first** (prefer Charge or Discord), then see which adjacent elements you need.
2. Lock your Main DPS's core element; fill adjacent elements to trigger reactions.
3. Fill remaining slots with chars whose **passives amplify the same reaction** (bench passives count).
4. Keep role balance (Main + Sub + Buffer + Survival).
5. Beyond the Rails late stages need **two teams** — raise a second reaction early.

## 5. FAQ

**Q: No S-ranks?**
A: A-rank swaps are usually same-element and reactions still fire (see budget alts). Esper Zero is a free story unit and a universal Cycle enabler.

**Q: Why is my damage low?**
A: Likely a broken reaction chain — a flex pick of the wrong element severs adjacent reactions and drops tiers. Preserve the reaction > single-card strength.

**Q: Need a dedicated healer?**
A: Not always. Adler/Fadia cover defense via shields/redirect; many top teams run no healer.
