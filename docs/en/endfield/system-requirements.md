# Arknights: Endfield System Requirements (2026)

Arknights: Endfield launched worldwide on **January 22, 2026** across **PS5, PC, Android, iOS, and the Epic Games Store**, with cross-platform save data. Below are the **minimum** and **recommended** specs per platform so you can tell whether your device will run it smoothly — and whether a PC upgrade is worth it.

## Platform overview

| Platform | Status | Notes |
|----------|--------|-------|
| PC (Windows) | Live | Via Hypergryph launcher / Epic |
| PlayStation 5 | Live | Cross-save |
| Android | Live | Partial HarmonyOS support |
| iOS / iPadOS | Live | iPhone XS / A12 and up |
| Epic Games Store | Live | Alternate PC entry |

## PC system requirements

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| OS | Windows 10 64-bit / Windows 11 64-bit | Same |
| DirectX | 11.1 or higher | Same |
| CPU | Intel Core i5-9400F or equivalent | Intel Core i7-10700K or equivalent |
| GPU | NVIDIA GeForce GTX 1060 or equivalent | NVIDIA GeForce RTX 2060 or equivalent |
| RAM | 16 GB | 16 GB or more |
| Storage | 50 GB+ free (extra 40 GB while extracting) | Install on an SSD |

> **SSD advice**: the publisher explicitly recommends an SSD. Extraction temporarily needs ~40 GB extra, so leave headroom.

## Mobile & console specs

- **Android**: Android 10.0+; minimum Snapdragon 855 / Dimensity 1000 / Kirin 990, recommended Snapdragon 8+ Gen1 / Dimensity 9000 / Kirin 9000S; RAM 6 GB min / 8 GB rec; 25 GB+ storage.
- **iOS / iPadOS**: iOS 15.0 / iPadOS 15.0+; minimum iPhone XS / A12, recommended iPhone 13 Pro / A15; RAM 4 GB min / 6 GB rec; 25 GB+ storage.
- **PS5**: 60 GB+ storage.

## FAQ

**Q: How much disk space does Endfield need?**
A: At least 50 GB on PC, with ~40 GB extra needed temporarily during extraction. Install on an SSD and keep ~90 GB free to be safe.

**Q: Can a GTX 1060 run it?**
A: Yes — it is the official minimum GPU. Expect lower settings; for a smoother experience see the recommended spec (RTX 2060 and up).

**Q: Is there a Mac version?**
A: The officially announced platforms are PC (Windows), PS5, Android, iOS, and Epic. No macOS version has been announced.

**Q: Does progress carry across devices?**
A: Yes. The same account syncs across platforms under one UID.
