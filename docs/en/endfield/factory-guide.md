# Endfield Factory (AIC) Beginner Guide

Many **Arknights: Endfield** players stall early because they never grasp the **AIC (Automated Industrial Complex)** — it's half the game and the source of operator materials, Stock Bills, and gacha tickets. **A running factory produces offline**; skip it and you leave massive progression on the table.

This guide uses "get the concept, then copy three lines" so the industrial loop doesn't scare you off.

## 1. Core Concept in Three Sentences

1. **Loop**: mine → refine → assemble → automate → feed progression.
2. **Runs offline**: once wired, lines produce 24/7 even when you're away.
3. **Power is life**: every machine must be powered; blackout halts the whole line — the #1 newbie trap.

## 2. Power System: Power First, Then Lines

### Key components
| Component | Role |
|---|---|
| **PAC (Protocol Anchor Core)** | base hub; yellow radius = powered zone; all structures must be inside |
| **Relay Tower** | extends grid from a powered source; **≤ 80 m between towers** |
| **Electric Pylon** | wireless power in a local radius; link to relay towers |
| **Thermal Bank** | main generator; burns Originium ore / batteries; **switch to batteries ASAP** |
| **Blue Battery** | uses Ferrium instead of Amethyst; far more power per unit (late game) |

### ⚠️ Avoid the "Power Death Spiral"
Full blackout → Shredding/Packaging stop → no batteries → Thermal Banks stop → total shutdown.
**Fix**: always keep one Thermal Bank tied to a dedicated Originium miner as backup power.

### Tip: Reverse Building
Build unpowered relay chains "backwards" from a distant node toward your base; once the chain connects, everything powers up — great for far ore.

## 3. Three Starter Lines (copy to run)

Unlock: **beat Chapter 1 boss, account Lv10–11, open tech tree** — start immediately, don't wait.

### Line 1: Self-Feeding Planting (Buckflower seed loop)
- 1 **Seed Picking Unit** → 2 **Planting Units**; loop one flower back to Seed Picking, surplus to Protocol Stash.
- Foundation for capsules/medicine — **build first**.

### Line 2: Battery Line (mid-game king)
- Amethyst ore → Refining Unit → Fitting Unit (amethyst parts)
- Originium ore → Shredding Unit (powder)
- Both → **Packaging Unit** → batteries
- Batteries feed Thermal Banks far more efficiently than raw ore — the key to your power ceiling.

### Line 3: Capsule / Explosive Line
- **Buck Capsule**: Amethyst→Refining→Molding (bottle) + Buckflower→Molding (powder) → Filling Unit; trade at Valley IV outposts for Stock Bills.
- **Industrial Explosives**: Amethyst parts + Aketine powder → Packaging Unit; breaks red-rock obstacles.

## 4. Tech Tree Priority

`Power` → `Logistics (all)` → `Field Stash` → `Pylon Relaying` → `Depot Bus`

- **Always upgrade Power first**; early capacity is low, count wattage per machine.
- Unlock belts & bus system before expanding.

## 5. Outposts: The Hidden Passive Income

Outposts carry sub-PACs and supply orders — **auto-complete orders every minute, awarding Conference Vouchers** (gacha tickets, mats).
- Link main-base lines to outpost storage for zero-manual supply.
- Upgrade outposts for better orders; assign liaison operators with dispatch bonuses (e.g. Antal).
- 4 daily delivery tasks grant regional dispatch vouchers to scale production.

## 6. Newbie Pitfalls — 5 Rules

1. **Claim ore nodes immediately** — nodes aren't infinite; hand-mine a starter batch, then automate with Electric Miners.
2. **Zone by function** — mining / processing / assembly separated; no crossed belts (use Belt Bridges).
3. **Use Protocol Stash** — dumps items to storage, kills long return belts, tighter layout.
4. **Deletion is free** — ugly layout? Tear down; no penalty. Efficiency comes from iteration.
5. **Don't lose the main story to the factory** — new buildings/tech gate behind story; balance factory with operator levels.

## 7. FAQ

**Q: When to start the factory?**
A: Right after Chapter 1 boss unlocks the tech tree. Earlier = more passive income.

**Q: Production stalled?**
A: Usually a bottleneck — add a second input machine (e.g. 2nd Refining) to match rates, or you blacked out.

**Q: Can I import blueprints?**
A: Yes. AIC mode → F1 → Shared Blueprints → paste code to import a whole line (server-locked; cross-server needs manual rebuild).
