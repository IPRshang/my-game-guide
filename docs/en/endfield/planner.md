# Endfield Base Planner

Use this interactive tool to plan your factory layout before you build. Adjust each
building's quantity and watch totals update live.

<EndfieldPlanner />

## How to read it

- **Total Power** must stay at or above `0`. If it drops negative, add Reactors or cut
  power-hungry buildings.
- **Total Pop** shows how many operators your base employs — useful for planning logistics
  assignments.
- **Output** is a quick reminder of what each building contributes.

## Tips

- Always place **Reactors** first in your real base.
- Pair **Workshops** with enough **Pop**-generating logistics operators.
- Revisit after each version patch as building stats change.
