# Black Myth Wukong — Build Guide

> From beginner to master — find your perfect combat style

## 1. Crit Assassin (Recommended for Beginners)

**Core Idea**: High crit rate + fast attacks. Melt bosses before they can react.

**Gear**:
- Weapon: Ruyi Jingu Bang (Crit +12%)
- Head: Golden Headband (Attack Speed +15%)
- Armor: Wanderer's Light Armor (+20% damage after dodge)
- Legs: Somersault Cloud Boots (Move Speed +10%)

**Skills**:
- Immobilize (core control)
- Rock Solid (safety net)
- Fiery Eyes (doubles crit rate)

**Combo**: Immobilize → Charged Heavy → Light chain → Dodge → Repeat

## 2. 72 Transformations (Advanced)

**Core Idea**: Rapid form-switching, exploiting i-frames from each transformation.

**Gear**:
- Weapon: Mind Stick (+25% transformation damage)
- Armor: Transformation Robe (-20% transformation cooldown)
- Accessory: 72 Transformations Tome (+2 form slots)

**Recommended Forms**:

| Form | Use Case |
|------|----------|
| Giant Ape | High-HP boss DPS race |
| Falcon | Rapid repositioning, dodge AoE |
| Clam | Defensive counter, poison immunity |

## 3. Tank Build (Accessibility Pick)

**Core Idea**: Stack the thickest armor, take the hardest hits.

**Gear**:
- Weapon: Vajra Staff (heal on block)
- Armor: Indestructible Golden Body Heavy Armor (40% damage reduction)
- Accessory: Longevity Lock (+30% max HP)

**Core Skills**: Rock Solid (maxed), Diamond Body (passive)

**Playstyle**: Block → Counter → Heal → Block again. Yes, it's that straightforward.

## 4. Staff Master (Expert Only)

**Core Idea**: Seamlessly chain all three staff stances for maximum DPS.

- Smash Stance (armor break) → Thrust Stance (launch) → Pillar Stance (finisher)
- Requires precise timing on stance swaps
- Highest damage ceiling, highest execution barrier
