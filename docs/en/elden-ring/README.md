## Starting Class Selection

| Class | Rating | Traits | Best For |
|-------|:---:|--------|----------|
| Vagabond | ⭐⭐⭐⭐⭐ | High HP, heavy load, great starting gear | Strength / Faith |
| Astrologer | ⭐⭐⭐⭐ | Powerful starting spells, long range | Pure Sorcery |
| Samurai | ⭐⭐⭐⭐⭐ | Uchigatana bleed, longbow ranged | Dex / Bleed |
| Prisoner | ⭐⭐⭐ | Estoc + Magic, versatile | Dex/Int hybrid |
| Prophet | ⭐⭐⭐ | Starts with healing incantation | Pure Faith |

---

> **New Player Tip**: Pick **Vagabond** or **Samurai**. High survivability, less dying. Starting class only matters early — everything is flexible later.
