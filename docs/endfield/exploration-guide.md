# 终末地 高效探索：宝箱路线与体力分配

终末地的开放世界能逛，但「逛得值不值」和多数开放世界不一样。社区里一个共识是：**宝箱收益相对投入太低**——几十个箱子攒起来的奖励，可能才抵得上一次抽卡。再加上解谜重复、隐形墙多、机动方式有限，盲目全图搜箱是很亏的。这篇帮你把体力花在刀刃上。

## 一、宝箱收益为什么「不划算」

终末地的宝箱不是不能开，而是**单位时间回报偏低**。经验上，开几十个宝箱换来的资源，约等于一次抽卡的量级。考虑到开箱要跑图、要解小谜题、要绕隐形墙，时间成本远高于那点收益。

结论不是「别开箱」，而是「别把开箱当主要资源来源」。把它当作顺路捡漏，而不是每日功课。

## 二、探索里的三个真实痛点

1. **环境解谜重复**：大量谜题是同一套「按按钮序列」的变体，做多了疲劳感强，新鲜感低。
2. **隐形墙多**：地图看着能走，实际被空气墙挡住，跑图容易白费路程，挫败感明显。
3. **机动受限**：没有攀爬、也没有滑翔，只有基础跳跃和**缆车（zipline）**。垂直空间和远点都得靠既有的缆车网络，自由度受约束，跑图效率上不去。

这三点叠加，让「地毯式探索」的性价比进一步下降。

## 三、优先级：主线与日常先于搜箱

更稳的资源节奏是：

- **先推主线**：剧情和关卡推进给的固定奖励远高于散箱，且解锁后续系统。
- **再做日常**：每日任务给稳定货币（如 Oroberyl 约 200/天），是可持续的抽卡来源，别为搜箱跳过。
- **宝箱顺路拿**：跑任务途中遇到的箱子顺手开，不必专门绕路清图。

想算清货币来源与每日产出，可看 [Endfield 货币系统图解](/endfield/currencies)。

## 四、体力（Stamina）怎么花最值

终末地的体力应优先投向**高回报、可重复**的活动，而不是低密度的搜箱：

1. **每日任务 / 日常委托**：稳定、低成本，优先级最高。
2. **可刷的资源点**：喂给工厂产线（电池、胶囊、Sandleaf 等）的素材，长期回报高于一次性宝箱。
3. **哨站订单**：被动产出会议凭证，和日常形成复利。
4. **宝箱**：仅作为顺路行为，不单列体力预算。

简单公式：**体力 → 日常 + 产线素材 > 一次性宝箱**。

## 五、搜箱路线的小技巧

如果你仍想清理某个区域的箱子，建议这样降成本：

- 沿**缆车网络**规划路线，用既有机动点串起箱子，减少步行绕墙。
- 先开「任务顺路」的箱，剩下的等有了更高效的移动手段再补。
- 把解谜箱当彩蛋，不为几个按钮序列专门跑远路。

## 六、常见疑问

**Q：宝箱要不要全清？**
A：不建议当作目标。几十个宝箱收益才约等于一次抽卡，全清时间成本太高，顺路拿即可。

**Q：为什么跑图总觉得别扭？**
A：隐形墙多、又不能攀爬滑翔，只能基础跳跃加缆车，机动自由度天然受限，跑图效率偏低是设计使然。

**Q：体力优先给什么？**
A：优先每日任务与可重复刷的资源点（喂工厂产线），宝箱放最后，当顺手行为。

**Q：解谜值得做吗？**
A：多为重复按钮序列，新鲜感低；除非奖励正好是你缺的素材，否则不必专门投入。新手整体节奏参考 [Endfield 新手指南](/endfield/beginner)。
