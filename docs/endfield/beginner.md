# 终末地 新手攻略

刚玩明日方舟：终末地？这是你开局几小时的高效路线。

## 开局清单

1. **推主线** 直到解锁基地（工厂）系统。
2. 去 [兑换码页](./codes.md) **领兑换码** —— 免费素材前期复利明显。
3. 在基地 **培养一名物流干员** 启动被动产出。
4. **做教学战斗** 熟悉即时战术与干员切换。

## 资源优先级

- **产能** —— 基地的命脉。没有足够反应堆前别超建消耗建筑。
- **稀有素材** —— 囤着；中期制造开销涨得很快。
- **干员经验** —— 聚焦核心 4–6 名，而非全员。

## 基地搭建技巧

- 先放 **反应堆**，再放生产建筑，永远别撞上产能赤字。
- 用 [基地规划器](./planner.md) 在落定前预览总产能。
- 物流干员缩短制造时间 —— 早投资。

## 常见误区

- 把升级摊到太多干员（阵容单薄）。
- 忽视产能上限、超建工厂。
- 跳过兑换码与邮件奖励。

## 下一步

- 看 [干员节奏榜](./tier-list.md) 决定抽谁。
- 用 [基地规划器](./planner.md) 规划布局。
