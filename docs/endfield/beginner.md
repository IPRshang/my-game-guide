# 终末地 新手开局怎么玩？

**Endfield 新手开局优先推主线解锁核心系统，用预注册/登录奖励的抽卡资源锁定一名强力的 6 星干员，并尽早搭建自动化工业线（AIC）减轻后期养成压力。**

## 开局步骤

1. 完成序章教学，解锁「自动化工业复合体（AIC）」基地系统
2. 领取 3500 万预注册奖励（约 135 抽等价资源），抽首期限定 6 星（如 Laevatain / Gilberta / Yvonne）
3. 推主线到能打「复刷（reroll）」前，先确定初始号目标角色
4. 每日清体力、签到、完成里程碑，积累材料
5. 中期重心转向 AIC 产线规划与干员编队（4 人小队，元素协同）

## 资源与基地优先级

- **产能** 是基地命脉：先放反应堆再放生产建筑，别撞上产能赤字。
- **干员经验** 聚焦核心 4–6 名，而非全员平摊。
- **稀有素材** 囤着，中期制造开销涨得很快。

## 常见问题

**Q：终末地新手开局先做什么？**
A：推主线解锁 AIC 基地系统 → 领取预注册抽卡资源锁定一名 6 星 → 清体力签到积累材料 → 中期规划产线与编队。

**Q：终末地基地怎么布局不亏产能？**
A：先放反应堆再放生产建筑，确保总产能不为负；物流干员能缩短制造时间，建议早投资。
