# 终末地 干员节奏榜

一份务实的「前期该投资哪些干员」排名。终末地同时有 **战斗干员** 与 **基地/物流干员**，好阵容要同时支撑工厂与战场。

## S 级 —— 优先抽优先养

- **物流 / 反应堆干员** —— 直接提升基地产出，反哺整个账号。前期优先搞到一个强物流单位。
- **AoE 输出干员** —— 在即时战斗段落快速清波。

## A 级 —— 稳定核心

- **单体爆发** —— 打 Boss 与精英怪。
- **护盾 / 坦克干员** —— 长线自动战中保住后排。

## B 级 —— 特定场景

- **控制** —— 特定关卡强，泛用性较低。
- **辅助 / 增益** —— 核心成型后更好用。

## 怎么用这份榜

1. 首次抽取优先 **S 级物流干员**（若有）—— 基地经济会复利增长。
2. 用 A 级输出与坦克补战斗缺口。
3. 核心队稳定前别在 B 级上过度投入。

> 排名随新干员与平衡补丁变动，每次版本更新后复查。
