# 明日方舟：终末地 攻略中心

**明日方舟：终末地（Arknights: Endfield）** 是鹰角网络（Hypergryph）出品的 3D 工业科幻 RPG，于 **2026 年 1 月 22 日** 全球上线。它把「基地自动化（产线、物流、反应堆）」与「即时战术战斗」结合，是方舟系列的全新变体，已吸引数百万预约玩家。

如果你搜的是 `终末地 兑换码`、`终末地 节奏榜` 或 `终末地 基地规划`，那来对地方了。本中心汇总了一名新干员所需的一切。

## 为什么值得做终末地攻略站

- **上线窗口期** —— 仍在发售首年内，大 wiki 尚未完全饱和，长尾词仍有排名机会。
- **建造重度玩法** —— 玩家高频提问「基地怎么布局」「先抽哪个干员」「兑换码在哪领」。
- **长线运营** —— 新干员、活动、兑换码持续更新，站点有稳定可写的话题。

## 快速上手

1. 推 **主线** 直到解锁基地（工厂）系统。
2. 先去 [兑换码页](./codes.md) 领可用码，过期不候。
3. 用 [节奏榜](./tier-list.md) 决定首次抽取方向。
4. 打开 [规划器](./planner.md) 在超建前平衡产能。
