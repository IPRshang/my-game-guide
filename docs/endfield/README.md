# 明日方舟：终末地 攻略中心

**明日方舟：终末地（Arknights: Endfield）** 是鹰角网络（Hypergryph）出品的 3D 工业科幻 RPG，于 **2026 年 1 月 22 日** 全球上线。它把「基地自动化（产线、物流、反应堆）」与「即时战术战斗」结合，是方舟系列的全新变体，已吸引数百万预约玩家。

如果你搜的是 `终末地 兑换码`、`终末地 节奏榜`、`终末地 基地规划` 或 `终末地 新手怎么玩`，本中心汇总了一名新干员所需的一切，并随版本持续更新。

## 新手开局路线

1. 推 **主线** 直到解锁基地（工厂）系统。
2. 先去 [兑换码页](./codes.md) 把可用码领完，过期不候。
3. 用 [节奏榜](./tier-list.md) 决定首次抽取方向，再开 [规划器](./planner.md) 在超建前平衡产能。
4. 卡关时回看 [战斗技巧](./combat-tips.md) 与 [探索指南](./exploration-guide.md)。

> 刚玩终末地？收藏本中心 —— 兑换码与节奏排名会随版本更新。

## 玩家最关心的三件事

- **兑换码**：官方在社群不定时发放，[兑换码页](./codes.md) 同步整理可用码与有效期。
- **先抽谁**：版本更迭会改变干员强度，[节奏榜](./tier-list.md) 按开荒/长线给出建议。
- **基地别乱建**：先用 [规划器](./planner.md) 算产能，再照 [工厂攻略](./factory-guide.md) 落地产线。
