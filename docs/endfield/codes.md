# 终末地 兑换码 — 领取与兑换

兑换码是终末地里最快拿到开荒素材的方式之一。本页讲清 **兑换码在哪出现** 和 **怎么使用**，并作为社区资源持续追踪可用码。

## 兑换码怎么用

1. 从主菜单打开 **设置**。
2. 进入 **账号 / 兑换** 页签。
3. 粘贴或输入兑换码并确认。
4. 奖励会发到游戏内 **邮件** —— 去邮件里领取。

> 兑换码通常 **区分大小写** 且 **限时**，找到尽快兑换。

## 终末地兑换码在哪发

- **官方 Discord** —— 活动与里程碑码最常见的发放点。
- **预约里程碑** —— 上线活动期间达成。
- **游戏内邮件** —— 部分码直接送达，无需手动输入。
- **联动 / 社媒活动** —— 关注官方 X（Twitter）与 YouTube。
