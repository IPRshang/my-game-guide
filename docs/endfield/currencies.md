# Endfield 货币系统完全图解

刚进《明日方舟：终末地》（Arknights: Endfield），很多人第一反应是："这游戏不是在玩游戏，是在做财务。"红币、金币、股票券、各种 permit 长得像、用途却天差地别——这是终末地玩家吐槽最多的痛点（社区里叫它 *currency confusion*）。

这篇把每一种货币拆干净：**它是什么、用来干嘛、从哪来、最容易和谁搞混**。文末还放了一个**抽卡规划器**，输入你手头的 Oroberyl 就知道该冲还是该存。

## 一、抽卡相关货币

### Oroberyl（奥罗贝利尔）—— 主抽卡货币
- **用途**：在 Headhunting 卡池抽角色。1 抽 = 500 Oroberyl，十连 = 5,000。
- **获取**：开放世界探索（最大早期来源，开图给的比被动多得多）、宝箱、每日任务（约 200/天）、账号等级奖励、活动、Origeometry 1:75 兑换。
- ⚠️ **别和 Origeometry 搞混**：Oroberyl 是"抽卡币"（红），Origeometry 是"付费币"（金）。

### Origeometry（奥里几何）—— 付费货币
- **兑换比**：1 个 = 75 Oroberyl。
- **用途**：兑换 Oroberyl、回 Sanity（40/个，**不建议常规用**）、解锁 Battle Pass、未来皮肤。
- **获取**：主线、Energy Allevium 战场挑战、氪金。
- **策略**：F2P 别拿它补抽卡，除非真急；性价比最高的是解锁 Battle Pass（29 换约 32 回报）。

### Headhunting Permit（招募许可）
- **Basic HH Permit**：标准池，不会过期。
- **Chartered HH Permit**：限定池专用，**绑定特定卡池、过期作废**（如 Firewalker's Trial 仅 Laevatain 可用，卡池结束即失效）。
- **New Horizons Permit**：新手十连券。

### Arsenal Ticket（军械票）
- **获取**：抽角色时获得（4★→20、5★→200、6★→2000 张）。
- **用途**：武器卡池（Arsenal Exchange）/ 军械交易所抽或买武器。
- **本质**：抽角色的副产物，**白嫖武器的来源**，不用单独肝。

## 二、通用与升级货币

### T-Creds（T 币 / 塔洛斯信用）
- **用途**：通用货币，升级角色、强化武器、建造基地设施到处都要——需求常量极大。
- **获取**：每日任务、Quota Exchange、Stock Redistribution 商店、Protocol Space、宝箱。

### Credits（信用点）
- **每日上限 300**，在 Credit Store 消费（含 Oroberyl、HH 许可、军械票、T 币、各类素材）。
- ⚠️ **每日 server reset 清零超出部分，当天必须花掉！**
- Credit Store 在**第一章 Process 2 后解锁**。

## 三、区域货币（不共享！）

### Stock Bills（区域股票券）
- **Valley IV Stock Bill / Wuling Stock Bill**，仅在本区域有效。
- **用途**：区域商店换物资 / 武器 / 蓝图、升级设施、造装备。
- ⚠️ **每个地图的货币不互通**，别在 Valley 囤了一堆券跑去 Wuling 用——用不上。

## 四、配额（来自重复角色）

| 配额 | 来源 | 用途 |
|---|---|---|
| AIC Quota | 抽限定池获得 | Quota Exchange 换素材 / 资源 |
| Bond Quota | 抽到重复角色获得 | 换奖励，含 HH 许可 |
| Endpoint Quota | 6★ 重复溢出才产 | 换昂贵的 6★ 武器 |

## 六、玩家最常踩的 3 个坑

1. **"红币金币分不清"** → Oroberyl（红，抽卡）≠ Origeometry（金，付费）≠ T-Creds（通用）。
2. **"信用点攒着下个月用"** → 每天 300 上限，过期直接作废，当天花。
3. **"全图通用券"** → 区域股票券各区域独立，囤错区白囤。

> 一句话记住核心循环：**探索攒 Oroberyl → 抽角色 → 重复变 Arsenal Ticket / Quota → 升级提效 → 更高效地farm**。把这个循环跑顺，货币焦虑就消失了。
