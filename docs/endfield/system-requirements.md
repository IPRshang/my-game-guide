# 终末地 配置要求（2026）

《明日方舟：终末地》已于 **2026 年 1 月 22 日** 全球上线，覆盖 **PS5、PC、Android、iOS、Epic 游戏商店** 多平台，且同账号数据互通。下面按平台列出**最低**与**推荐**配置，帮你判断设备能否流畅运行，以及 PC 端要不要升级。

## 平台总览

| 平台 | 上线情况 | 备注 |
|------|----------|------|
| PC（Windows） | 已上线 | 经鹰角启动器 / Epic 下载 |
| PlayStation 5 | 已上线 | 数据互通 |
| Android | 已上线 | HarmonyOS 部分支持 |
| iOS / iPadOS | 已上线 | iPhone XS / A12 起 |
| Epic Games Store | 已上线 | PC 端另一入口 |

> 想在开服第一天就进塔卫二？先看下面的配置表，别等下载完才发现设备带不动。

## PC 配置要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 64-bit / Windows 11 64-bit | 同左 |
| DirectX | 11.1 及以上 | 同左 |
| 处理器 | Intel Core i5-9400F 或同等 | Intel Core i7-10700K 或同等 |
| 显卡 | NVIDIA GeForce GTX 1060 或同等 | NVIDIA GeForce RTX 2060 或同等 |
| 内存 | 16 GB | 16 GB 及以上 |
| 存储 | 50 GB 以上空闲（解压时额外需 40 GB） | 建议安装在 SSD |

> **SSD 建议**：官方明确建议装在固态硬盘，解压阶段会临时多占约 40 GB，预留空间务必留足。

## 手机与主机配置

- **Android**：Android 10.0 及以上；最低骁龙 855 / 天玑 1000 / 麒麟 990，推荐骁龙 8+ Gen1 / 天玑 9000 / 麒麟 9000S；运行内存最低 6 GB、推荐 8 GB；存储 25 GB+。
- **iOS / iPadOS**：iOS 15.0 / iPadOS 15.0 及以上；最低 iPhone XS / A12，推荐 iPhone 13 Pro / A15；运行内存最低 4 GB、推荐 6 GB；存储 25 GB+。
- **PS5**：存储 60 GB 以上。

## 常见问题

**Q：终末地需要多少硬盘空间？**
A：PC 端至少预留 50 GB，解压过程中会临时多占约 40 GB，建议装在 SSD 并预留 90 GB 以上更稳妥。

**Q：GTX 1060 能玩吗？**
A：可以，这是官方列出的最低显卡。能跑起来，但画质与帧率建议调低；想要更稳的体验看推荐配置（RTX 2060 起步）。

**Q：Mac 能玩终末地吗？**
A：目前官方公布平台为 PC（Windows）、PS5、Android、iOS、Epic，未提及 macOS 版本。

**Q：手机和 PC 进度互通吗？**
A：互通。同一账号在不同平台数据同步，各平台为同一 UID。
