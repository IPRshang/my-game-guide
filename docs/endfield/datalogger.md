# Endfield Datalogger 气球人解锁教程

你在 Talos-II 到处跑图时，一定见过那些**黄色、会挥手的小气球人**——站在写着 "connecting" 的台座上。凑上去交互，却只蹦出一句：

> *"Access authorization cannot be verified. Please acquire access authorization before starting again."*
> （无法验证访问授权，请先获取访问授权。）

很多人以为这是环境解谜、要找隐藏道具，于是在附近绕了半天。**其实根本不是。** 这篇讲清楚它到底怎么解锁、解锁后能干嘛。

## 一、为什么早期用不了

Protocol Datalogger（协议数据记录器）的访问授权**绑定主线剧情进度**，不是靠解谜或捡东西。你早期看到它却用不了，是正常的——别浪费时间找隐藏开关。

## 二、解锁步骤（3 步）

1. **推进主线到「第一章 流程 I」（Chapter I Process I）全部完成**
   - 包含：拯救 Hub Base（中枢基地）
   - 前往 **Valley Pass（谷口）** 对抗 **Landbreakers（破界者）**
2. **返回中枢后，找 Andre 对话**
   - 对话结束即获得气球人的访问授权
3. **此后所有 Datalogger 可在地图上一键标记**，边探索边收集

> 一句话：**打完第一章流程 I、回基地和 Andre 说句话，气球人就开始工作了。**

## 三、解锁后能干嘛：AIC Index

交互气球人后会获得资源 **AIC Index**，它用于 **AIC Plan（AIC 计划）** 中研究工厂科技：

- 建造更多生产单位
-  crafting 新素材
- 提升整体产能

对终末地这种"强制工厂 + 电网 + 交易"玩法的游戏，AIC Index 是中后期产能扩张的关键燃料。**早解锁 = 早积累 = 工厂滚雪球更快。**

## 四、常见疑问

- **气球人需要解谜吗？** 不需要，纯剧情解锁。
- **错过了 Andre 对话？** 主线推进后会自动获得，回中枢留意角色头顶提示。
- **Datalogger 在哪？** 全图散布，授权后地图上会标出，顺路收即可。
