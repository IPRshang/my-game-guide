# 《黑神话：悟空》棍法姿态指南

**《黑神话：悟空》给你三种棍法姿态——劈、立、戳。每种都改变你如何攒与花"式"（专注/元气），如何打出重击，以及你能在多安全的情况下造成伤害。战斗中切换姿态，是这套战斗系统的核心。**

## 三种姿态

| 姿态 | 特征 | 最适合 |
|---|---|---|
| **劈** | 蓄力下砸重击，消耗式打出爆发伤害 | 闪避后的爆发输出 |
| **立** | 站上棍身躲地面攻击，再砸下 | 规避横扫与重新走位 |
| **戳** | 远距离戳刺，安全距离攒式 | 保持距离、稳妥蹭伤 |

## 式（专注）怎么联动

- 轻攻击 **攒式**；重攻击 **花式**。
- 不同姿态攒式与花式的速率不同。
- 在对的时机花式——通常是成功闪避之后——是你大部分伤害的来源。

## 何时切换

1. **开局用戳**，从安全距离攒式。
2. **闪过 Boss 一套后切劈**，打一套重击惩罚。
3. **Boss 频繁横扫或地面 hazard 时切立**，规避并重新站位。
4. 等下一个破绽时 **切回戳**。

## 小贴士

- 别整场站一个姿态——切换姿态才是设计意图里的伤害循环。
- 立姿不只是花活；它对某些地面攻击是硬counter。
- 练重击的时机，而非只练姿态选择——时机决定你打中还是挨打。

## 常见问题

**Q：哪种姿态最强？**
A：没有万能的——戳最安全，劈最痛，立最守。好的打法是三者轮换。

**Q：能自由切换姿态吗？**
A：能，战斗中随时可以切换。

**Q：姿态影响攒式吗？**
A：影响，每种姿态攒式与花式速度不同，这正是切换的意义。
