## 📊 珍玩系统总览

珍玩是黑神话的核心装备系统之一，最多可同时装备 **3个珍玩**，提供各种被动加成。

| 分类 | 数量 | 获取方式 |
|------|:----:|----------|
| 攻击型珍玩 | 12 | Boss掉落 / 商店购买 |
| 防御型珍玩 | 10 | 宝箱 / 隐藏区域 |
| 功能型珍玩 | 14 | 支线 / 探索 / NPC |
| 稀有珍玩 | 12 | 隐藏Boss / 真结局 |
| **总计** | **48** | |

> 💡 **珍玩搭配原则**：根据流派选择核心珍玩 → 补充生存向 → 功能型按需调整

## ⚔️ S级珍玩（必拿）

### 1. 【定风珠】
- **效果**：大幅减少受到的风力伤害，免疫部分吹飞效果
- **获取**：黄风大圣 Boss 战掉落
- **适用流派**：全流派通用
- **推荐度**：⭐⭐⭐⭐⭐
- **点评**：打黄风岭必备，后期也能防很多击退效果

### 2. 【琥珀光铠】
- **效果**：生命值低于30%时，防御力提升50%
- **获取**：第二章隐藏宝箱
- **适用流派**：莽夫流 / 立棍流
- **推荐度**：⭐⭐⭐⭐⭐
- **点评**：残血反杀神装，配合回血道具效果极佳

### 3. 【妙仙葫芦】
- **效果**：使用药品时回复量+30%
- **获取**：土地公商店购买（第二章解锁）
- **适用流派**：全流派通用
- **推荐度**：⭐⭐⭐⭐⭐
- **点评**：新手神器，大幅提升生存能力

### 4. 【金睛火眼符】
- **效果**：看破成功后攻击力提升20%，持续5秒
- **获取**：二郎神支线奖励
- **适用流派**：技术流 / 劈棍流
- **推荐度**：⭐⭐⭐⭐⭐
- **点评**：看破流核心，高手用了输出爆炸

### 5. 【九转金丹】
- **效果**：每60秒自动复活一次（每场战斗限一次）
- **获取**：真结局通关奖励
- **适用流派**：全流派通用
- **推荐度**：⭐⭐⭐⭐⭐
- **点评**：最强珍玩没有之一，相当于多一条命

## 🎯 各流派推荐珍玩搭配

### 劈棍流（平衡输出）
```
【暴击石】 + 【破甲符】 + 【嗜血玉】
```
- 核心思路：高暴击+破甲，击杀回血保持续航

### 立棍流（重击爆发）
```
【蓄力石】 + 【无双之魂】 + 【琥珀光铠】
```
- 核心思路：蓄力重击爆发，残血防反杀

### 戳棍流（灵活机动）
```
【突击戒指】 + 【连击护符】 + 【闪避戒指】
```
- 核心思路：连击叠伤害，完美闪避保安全

### 法术流（远程消耗）
```
【定身符】 + 【回蓝玉】 + 【法力石】
```
- 核心思路：定身+法术轰炸，高蓝量持续输出

### 召唤流（毫毛流）
```
【毫毛针】 + 【酒葫芦】 + 【幸运币】
```
- 核心思路：召唤物输出，自己躲后面
