# 《黑神话：悟空》变身指南

**变身让《黑神话：悟空》里的你暂时化作被击败的敌人或 Boss，获得其招式组与一条独立血条。它们消耗法力（或冷却资源），持续有限时间，因此是一次战术爆发，而非永久状态。**

## 机制怎么运作

- 通过 **击败特定敌人或 Boss** 并获取其形态来解锁变身。
- 激活变身后，你的 **招式组被替换为该形态** 的攻击。
- 变身拥有 **独立血条**——伤害消耗它，耗尽后你恢复原身。
- 持续时间与消耗因形态而异；越强的形式消耗越多、持续不同。

## 变身划算的时机

1. **打群怪**——很多形态有横扫，清小兵比棍子快得多。
2. **作为防御性重置**——独立血条等于第二条命。
3. **吃元素克制**——某些形态带 Boss 弱点的元素伤害。
4. **破韧**——重型形态能击退轻攻击打不动的 Boss。

## 不该变身的时机

- 你已背熟的紧凑 Boss 招式——自己的招式组往往更高效。
- 法力需要留给生存法术时。
- Boss 即将换阶段时——可能浪费持续时间。

## 小贴士

- **在战斗升级前变身**，别等血线见底，才能用满那条额外血条。
- 有条件就 **升级形态**——伤害随进度成长。
- **在土地庙多试**——你可以切换装备的是哪个变身。

## 常见问题

**Q：怎么拿到更多变身？**
A：击败特定 Boss 与敌人，部分情况下完成支线内容。

**Q：变身消耗生命吗？**
A：消耗法力或冷却资源，并带一条独立的额外血条。

**Q：有哪个变身最强吗？**
A：没有单个形态通吃——最好用哪个，取决于你需要控场、爆发还是生存。
