## 一、游戏背景简介

《黑神话：悟空》以中国古典名著《西游记》为蓝本，但讲述的是取经之后的故事。玩家扮演「天命人」——一只为寻回孙悟空（齐天大圣）遗骸与「五件根器」而踏上征途的猴子。

游戏科学基于中国各地真实古建筑与文物进行扫描建模，美术与配乐高度还原中式神话氛围。截至 2026 年，全球销量已突破 **3000 万份**，是国产单机销量天花板。续作《黑神话：钟馗》已于 2025 年公布（早期开发）。

> 本攻略默认**不剧透主线剧情与 Boss 真名**，仅提供机制与打法思路。

## 二、核心玩法机制说明

黑神话是「魂类 + 西游记变身」的融合动作游戏，核心系统如下：

- **棍法四势**：劈棍（快攻）、立棍（对群/防下段）、戳棍（突刺破防）、奇棍（特殊派生）。长按攻击键可蓄力，松手释放对应棍势。
- **法术系统**：如「定身术」（定住敌人，破防关键）、「聚形散气」（分身骚扰）、「身外身法」（毛猴群攻）、「安身法」等，消耗法力，需搭配「落钱/泡酒」回蓝。
- **变化（变身）**：击败特定妖王后可习得变身，变身期间获得新招式与血量，是打断 Boss 大招的重要手段。
- **泡酒与丹药**：酒类提供持续回复/增益，丹药为即效 consumable，Boss 战前务必配好。
- **影神图（妖怪图鉴）**：击败妖怪掉落「灵蕴」并收录图鉴，集齐可解锁背景故事与属性加成——既是收集也是养成。
- **土地庙（存档点）**：兼作存档、分配属性点、重铸装备、洗点（消耗「九转金丹」）的据点。

## 三、新手入门要点

1. **先定流派方向**：开局不必纠结，但建议先看 [流派配装](./builds) 选一个主方向（劈棍压制 / 立棍苟活 / 法术流 / 变身流）。
2. **学会「看破」（精准闪避/格挡）**：黑神话的精髓不是硬拼，而是观察敌人起手动作后精准闪避或格挡，命中弱点可削韧。
3. **别贪刀**：敌人大开大合时拉开距离，宁可少打两下也要保命——尤其 Boss 二阶段。
4. **优先堆「根器·身」（血量）**：新手前期把属性点倾向生命与防御，容错率远高于纯输出。
5. **善用定身术**：对绝大多数 Boss，定身→重棍连段是通用起手式。
6. **常回土地庙**：升级、洗点、配装都在土地庙，卡关时先回去调整 Build 再战。
7. **收集影神图**：顺路清小怪不仅攒灵蕴，还能解锁强力被动。

## 四、进阶技巧与策略

- **四段棍势满蓄**：劈棍满蓄伤害极高，配合「重棍不空」类珍玩可秒小怪、破 Boss 韧。
- **法术流 Build**：以「定身 + 聚形散气 + 身外身法」为核心，配高法力上限与回蓝酒，适合手残但需练习节奏。
- **弱点攻击**：多数 Boss 有可破坏部位或特定破防窗口，观察其红光/蓄力动作针对性输出。
- **变身救场**：被压制时切变身可重置仇恨并硬抗，是逃课与反打的灵药。
- **二周目（新游戏+）**：继承装备与等级，敌人更强但掉落更好，是冲全收集与真结局的必经之路。
- **隐藏 Boss / 支线**：部分妖王需完成支线或特定操作才出现，详见 [隐藏要素](./secrets)。

## 五、常见问题解答（FAQ）

**Q1：游戏太难了，有没有简单模式？**
A：没有传统难度选项，但可通过「堆血量 + 定身流 + 召唤援护（铜头铁臂等珍玩）」大幅降低门槛；也可等官方后续平衡补丁。

**Q2：DLC 出了吗？**
A：截至 2026 年 8 月，**大型付费 DLC 仍在开发中**，官方多次辟谣网传上线日期（如 6 月/9 月/定价 98 元等均不实），普遍预期 **2027 上半年**上线。本体已免费更新「连战模式（Boss Rush）」、章节地图、新披挂等。

**Q3：Xbox 能玩吗？**
A：能。Xbox Series X|S 版已于 2025 年推出，与 PS5/PC 内容一致。

**Q4：有几个结局？真结局怎么解锁？**
A：本体有多个结局分支，真结局需满足特定收集/支线条件，详见 [隐藏要素](./secrets)（含轻度剧透提示）。

**Q5：需要联网吗？**
A：单机全程离线可玩，无需联网；云存档依平台而定。

**Q6：新手推荐什么 Build？**
A：推荐「劈棍 + 定身术 + 高血量」的稳健组合，详见 [流派配装](./builds)。
