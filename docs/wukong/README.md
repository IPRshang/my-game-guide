## 新手建议

1. **不要贪刀** — 悟空的硬直惩罚很重，打 2-3 下就闪避
2. **定身术是神技** — 冷却好了就用，打 Boss 时定住后重击蓄力
3. **多探索** — 隐藏 Boss 给的奖励往往是质变级的
4. **变身不要浪费** — 变身期间是无敌的，用来躲致命技能
