# 黑神话悟空 — 流派配装推荐

> 从入门到精通，找到最适合你的战斗风格

## 1. 暴击刺客流（推荐新手）

**核心思路**：高暴击 + 快速攻击，在 Boss 反应过来之前打出成吨伤害。

**装备**：
- 武器：如意金箍棒（暴击 +12%）
- 头冠：紧箍咒（攻击速度 +15%）
- 护甲：行者轻甲（闪避后伤害 +20%）
- 腿甲：筋斗云靴（移动速度 +10%）

**技能**：
- 定身术（核心控制）
- 铜头铁臂（容错）
- 火眼金睛（暴击率翻倍）

**打法**：定身→重击蓄力→轻击连段→闪避→循环

## 2. 七十二变流派（进阶）

**核心思路**：频繁切换变身形态，利用各变身技能的无敌帧。

**装备**：
- 武器：随心铁杆兵（变身伤害 +25%）
- 护甲：变化道袍（变身冷却 -20%）
- 饰品：七十二变图录（额外解锁 2 个变身形位）

**推荐变身**：
| 变身 | 用途 |
|------|------|
| 巨猿 | 高血量 Boss 站桩输出 |
| 鹰隼 | 快速移动、躲避全屏技 |
| 河蚌 | 防御反击、毒免疫 |

## 3. 法坦流（手残福音）

**核心思路**：叠最厚的甲，挨最毒的打。

**装备**：
- 武器：金刚杵（格挡时回复生命）
- 护甲：不坏金身重甲（伤害减免 40%）
- 饰品：长生锁（最大生命 +30%）

**核心技能**：铜头铁臂（满级）、金刚不坏（被动）

**打法**：格挡→反击→吃药→继续格挡。是的，就是这么朴实无华。

## 4. 棍法宗师流（高手向）

**核心思路**：三种棍法形态无缝切换，最大化输出。

- 劈棍（破防）→ 戳棍（浮空）→ 立棍（终结）
- 需要精确掌握切换时机
- 伤害上限最高，操作难度最大
