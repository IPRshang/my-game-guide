# 黑神话悟空 — 流派配装 & 最强 Build 推荐

> 选对 Build，比多练两小时更省力。本文按「新手 → 进阶」梳理 **6 大主流流派**，给出加点、装备、珍玩与泡酒方案，帮你在土地庙洗点前就定好方向。

## 0. 选 Build 前必读

- **属性根器**：生命（身）、气力（性命）、攻击（力气）、法力（法）、变形（毫毛）。洗点在**土地庙**消耗「九转金丹」完成，卡关先回去调 Build 再战。
- **装备重铸**：披挂的词条可在土地庙「重铸」刷新，优先堆核心属性（暴击 / 伤害减免 / 法力上限）。
- **珍玩栏位有限**：一般 2–4 个，别贪多，集中强化你流派的核心机制。
- **泡酒与丹药**：Boss 战前务必配好回蓝酒（如「嫩玉藕」「蜂山石髓」）与即效丹药，续航决定 Build 上限。

---

## 1. 劈棍压制流（新手首选 ★★★★★）

**核心思路**：劈棍满蓄伤害极高、起手稳健，配合「定身术 + 高血量」先手压制，是首页首推的「劈棍 + 定身术 + 高血量」组合。

**加点**：生命（身）＞ 攻击（力气）＞ 气力（性命）。新手先把身板堆厚，再补输出。

**装备**：
- 武器：高暴击/高蓄力伤害的棍棒（如意金箍棒类，暴击 +12%）
- 头冠：增伤/暴击头冠（紧箍咒类，攻击速度 +15%）
- 护甲：轻甲（行者轻甲，闪避后伤害 +20%，保机动）
- 腿甲：移速靴（筋斗云靴，移动速度 +10%）

**珍玩**：铜头铁臂（容错）、重棍不空类（满蓄不落空，秒小怪破韧）。

**泡酒**：回蓝酒 + 减伤酒。

**连招**：定身 → 劈棍满蓄重击 → 轻击连段 → 闪避拉开 → 循环。对绝大多数 Boss 都通用。

---

## 2. 立棍苟活流（高生存 / 对群）

**核心思路**：立棍对群与防下段极强，蓄力时在棍梢上方无敌，适合被小怪围殴或 Boss 下段攻击多的场景。

**加点**：生命（身）≈ 防御（性命）＞ 攻击（力气）。

**装备**：
- 武器：立棍特化棍（立棍伤害 / 范围加成）
- 头冠：受击回血或减伤头冠
- 护甲：中甲（平衡机动与减伤）
- 腿甲：闪避距离靴

**珍玩**：长生锁（最大生命 +30%）、受击回蓝类。

**打法**：拉怪成群 → 立棍蓄力清场；Boss 下段技时立棍规避，落地接重击。

---

## 3. 戳棍破防流（单体爆发 / Boss 速杀）

**核心思路**：戳棍突刺破防、单体爆发最高，专治高韧 Boss 与需要快速破防的妖王。

**加点**：攻击（力气）＞ 暴击相关 ＞ 生命（身）。

**装备**：
- 武器：戳棍特化棍（突刺伤害 / 破防加成）
- 头冠：暴击头冠
- 护甲：轻甲（保出手速度）
- 饰品：暴伤饰品

**珍玩**：暴伤珍玩、破防加速类。

**连招**：定身 → 戳棍突刺破防 → 劈棍补刀 → 身外身法收尾。

---

## 4. 法术炮台流（定身 + 聚形散气 + 身外身法）

**核心思路**：以法术为核心输出与控场，高法力上限 + 回蓝酒支撑持续施法，适合不愿硬拼、偏好节奏打法的玩家。

**加点**：法力（法）＞ 生命（身）＞ 攻击（力气）。

**装备**：
- 武器：法术增伤棍
- 头冠：法力上限 / 回蓝头冠
- 护甲：法坦兼顾（减伤 + 法力）
- 饰品：法力回复 / 定身延长

**核心法术**：
- **定身术**：定住敌人，破防与起手关键
- **聚形散气**：分身骚扰、分担仇恨
- **身外身法**：毛猴群攻、爆发输出
- **安身法**：站桩回血续航

**泡酒**：高回蓝酒（嫩玉藕 / 蜂山石髓）必备。

**打法**：定身 → 聚形散气铺场 → 身外身法爆发 → 安身法续航，循环消耗 Boss。

---

## 5. 七十二变流派（变身无敌帧）

**核心思路**：频繁切换变身形态，利用各变身技能的无敌帧硬抗 Boss 大招、打断蓄力，是逃课与反打的灵药。

**加点**：变形（毫毛）＞ 生命（身）＞ 攻击（力气）。

**装备**：
- 武器：随心铁杆兵（变身伤害 +25%）
- 护甲：变化道袍（变身冷却 -20%）
- 饰品：七十二变图录（额外解锁变身形位）

**推荐变身**：
| 变身 | 用途 |
|------|------|
| 巨猿 | 高血量 Boss 站桩输出 |
| 鹰隼 | 快速移动、躲避全屏技 |
| 河蚌 | 防御反击、毒免疫 |

**打法**：被压制时切变身重置仇恨并硬抗，无敌帧内规避致命技，落地接爆发。

---

## 6. 法坦铜头铁臂流（手残福音）

**核心思路**：叠最厚的甲、挨最毒的打，靠减伤与格挡反制生存，操作门槛最低。

**加点**：防御（性命）＞ 生命（身）＞ 攻击（力气）。

**装备**：
- 武器：金刚杵（格挡时回复生命）
- 护甲：不坏金身重甲（伤害减免 40%）
- 饰品：长生锁（最大生命 +30%）

**核心技能 / 珍玩**：铜头铁臂（满级，精准格挡）、金刚不坏（被动减伤）。

**打法**：格挡 → 反击 → 吃药 → 继续格挡。朴实无华但稳。

---

## 珍玩 & 泡酒 通用推荐

- **铜头铁臂**：精准格挡反制，几乎所有流派都带。
- **长生锁**：最大生命 +30%，法坦/苟活流核心。
- **重棍不空类**：劈棍满蓄不落空，清场破韧神器。
- **回蓝酒（嫩玉藕 / 蜂山石髓）**：法术流命脉，其余流派也建议带一瓶。
- **减伤酒**：高压 Boss 战保命。

## FAQ

**Q1：黑神话悟空新手推荐什么 Build？**
A：新手首选「劈棍压制流」——劈棍满蓄高伤 + 定身术起手 + 优先堆生命（身），稳健易上手，详见上文流派 1。

**Q2：黑神话悟空哪个流派最强？**
A：没有绝对最强，取决于打法。「戳棍破防流」单体爆发最高、「法坦流」生存最稳、「劈棍压制流」综合最均衡。速查表按推荐度排序，新手从劈棍流起步最稳。

**Q3：黑神话悟空法术流怎么配装？**
A：法术炮台流主堆法力（法）与回蓝：武器选法术增伤棍，头冠堆法力上限，泡酒必带回蓝酒（嫩玉藕 / 蜂山石髓），核心法术为定身术 + 聚形散气 + 身外身法，详见流派 4。
