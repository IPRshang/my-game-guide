# 黑神话悟空 — 隐藏内容全攻略

> 游戏共有 5 个秘密区域（每章一个），全部完成才能解锁真结局。

## 真结局解锁条件

**前置条件：完成全部 5 个秘密区域 + 第三章 Treasure Hunter（寻宝人）任务**

1. 完成所有秘密区域后，前往第三章的 **大宝塔（Great Pagoda）**
2. 大宝塔壁画全部点亮后，弥勒佛（Maitreya）出现
3. 与弥勒佛对话，进入 **梅山（Mount Mei）**
4. 击败 **二郎神（Erlang, the Sacred Divinity）**
5. 二郎神变身后，天命人化为石猴形态，对战 **四大天王（Four Heavenly Kings）**
6. 击败四大天王后，二郎神再次变为巨兽形态，进行最终决战
7. 回到第六章，击败石猿（Stone Monkey）+ 大圣残躯（Great Sage's Broken Shell）触发真结局

**真结局奖励**：解锁隐藏过场动画，获得 Azure Dome 变身 + Tri-Point Double-Edged Spear。

## 5 大秘密区域（按章节）

### 第一章：古观音禅寺（Ancient Guanyin Temple）

**进入方法**：在苍狼林区域找到并敲响 **三口钟**

| 钟 | 位置 |
|---|------|
| 第一口 | 广智（Guangzhi）竞技场 |
| 第二口 | 广谋（Guangmou）竞技场 |
| 第三口 | 白衣秀士（Whiteclad Noble）竞技场 |

敲响第三口钟后自动传送至古观音禅寺。隐藏 Boss：**金池长老（Elder Jinchi）**

### 第二章：莎诃利国（Kingdom of Sahali）

**进入方法**：完成醉酒野猪（Drunken Boar）任务线
- 在黄风岭附近找到醉酒野猪 NPC
- 按任务提示找到醒酒物品
- 完成任务后解锁莎诃利国秘密区域
- 隐藏 Boss：**蝜蝂（Fuban）**

### 第三章：梅山（Mount Mei）

**进入方法**：通过大宝塔进入（需完成前 4 个秘密区域 + Treasure Hunter 任务）
- 大宝塔位于第三章区域
- 每完成一个秘密区域，大宝塔壁画会逐步填充
- 全部完成后弥勒佛出现，引导进入梅山
- 隐藏 Boss：**二郎神（Erlang Shen）**

### 第四章：紫云山（Purple Cloud Mountain）

**进入方法**：在第四章 **击败 Venom Daoist（虫总兵）两次**

| 次数 | 位置 |
|------|------|
| 第一次 | Webbed Hollow（盘丝洞） / Pool of Shattered Jade |
| 第二次 | Temple of the Yellow Flower（黄花观） / Court of Illumination |

第二次击败后，与墙壁互动进入紫云山。隐藏 Boss：**毒敌大王（Duskveil）**

### 第五章：碧水洞（Bishui Cave）

**进入方法**：完成五行车（Five-Element Carts）任务线
- 在第五章火焰山区域推进五行车相关任务
- 完成全部五行车解锁碧水洞入口
- 隐藏 Boss：**避水金睛兽（Bishui Golden-Eyed Beast）**

## 生肖村（Zodiac Village）— NPC 聚集地

生肖村（又称画中世界 / Painted Realm）不是秘密区域，但非常重要：

**解锁方式**：
1. 第三章北岸（North Shore）找到 **陈龙（Chen Loong）**
2. 击败陈龙后，从戌狗（Xu Dog）处获得特制壮骨丹
3. 将丹药交给陈龙，获得 **如意卷轴（Ruyi Scroll）**
4. 使用卷轴进入画中世界 / 生肖村

**生肖村 NPC**：
| NPC | 功能 |
|-----|------|
| 戌狗（Xu Dog） | 炼药（Medicine Crafting） |
| 申猴（Shen Monkey） | 葫芦升级（Gourd Upgrades） |
| 陈龙（Chen Loong） | 种植（Farming） |
| 寅虎（Yin Tiger） | 锻造 / 防具升级（Blacksmith / Armor Upgrades） |

## 隐藏 Boss 汇总

| Boss | 位置 | 说明 |
|------|------|------|
| Elder Jinchi（金池长老） | Ch1 古观音禅寺 | 敲三口钟后触发 |
| Red Loong（赤髯龙） | Ch1 | 使用 Loong Scale 解锁瀑布后区域 |
| Black Loong（黑髯龙） | Ch2 | 使用 Loong Scale 解锁 |
| Shigandang（石敢当） | Ch2 Fright Cliff | 收集 6 颗佛目珠（Buddha's Eyeballs）召唤 |
| Fuban（蝜蝂） | Ch2 莎诃利国 | 完成醉酒野猪任务 |
| Duskveil（毒敌大王） | Ch4 紫云山 | 击败 Venom Daoist 两次后 |
| Bishui Golden-Eyed Beast | Ch5 碧水洞 | 完成五行车任务 |
| Erlang Shen（二郎神） | Ch3 梅山 | 完成全部秘密区域，最强隐藏 Boss |

> **提示**：佛目珠（Buddha's Eyeballs）是第二章 Fright Cliff 区域的专属收集品，共 6 颗。集齐后在指定地点召唤隐藏 Boss 石敢当。佛目珠与大宝塔无关。
