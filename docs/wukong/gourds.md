# 《黑神话：悟空》葫芦指南

**葫芦是《黑神话：悟空》的主要回血道具——它装有一定次数的饮酒次数，在土地庙休息时回满。变化最大的不是回血量本身，而是你泡进去的酒与药材，它们会附加抗性、法力回复或临时增益等效果。**

## 基础

- 饮酒以 **恢复生命**；次数有限。
- **在土地庙（祠）休息会免费回满** 葫芦。
- 葫芦的 **容量可以随进度提升**，并收集升级材料。

## 酒与药材

- **酒** 改变饮酒时的效果——更强回血、持续恢复，或附加其它效果。
- **药材**（泡入的材料）在一段时间内附加抗性或属性收益。
- 你可以在土地庙切换配置，所以针对不同 Boss 多试试。

## 升级路线

1. 找到 **葫芦升级 NPC**（通常随进度在土地庙遇到）。
2. 消耗所需材料提升 **容量** 或 **效力**。
3. 前期优先容量——多一次饮酒通常比喝得更猛更实用。

## 实用小贴士

- **战斗早期就饮酒**，别等血线见底——饮酒动作会让你露出破绽。
- **酒要对着 Boss 选**——抗性酒打元素 Boss 效果明显。
- **别囤饮酒次数**——休息免费回满，探索时尽管用。

## 常见问题

**Q：怎么拿到更多回血？**
A：通过对应 NPC 用探索所得材料升级葫芦容量。

**Q：饮酒要消耗什么吗？**
A：不消耗——土地庙休息免费回满，没有需要打理的经济系统。

**Q：酒值得在 Boss 之间换来换去吗？**
A：值得。元素抗性与状态解除常常能决定最难的几场战斗。
