# 艾尔登法环 — 最强流派配装

## 1. 出血流（版本答案）

**加点**：生命力 50 / 感应 60 / 敏捷 40

**核心武器**：
- 尸山血海（战技尸横遍野，出血累积逆天）
- 双剥尸曲剑（跳劈四段伤害，Boss 融化器）
- 艾琉诺拉双头刀

**护符**：鲜血君王的欢愉 + 亚历山大碎片 + 义手剑士 + 腐败翼剑

**评价**：从 1.0 强到最后一版，唯一真神。

## 2. 法师流（远程安逸）

**加点**：智力 80 / 集中 40 / 生命力 40

**核心装备**：
- 卢瑟特辉石杖 / 卡利亚权杖
- 亚杜拉月光剑 + 彗星亚兹勒 + 黑夜彗星

**护符**：魔力对蝎 + 葛孚雷肖像 + 拉达冈雕像 + 蓝琥珀链坠+2

**灵药**：魔力破露滴 + 无限蓝破露滴

**连招**：无限蓝灵药 → 灵魂激流（彗星亚兹勒）→ 一键蒸发 Boss

## 3. 巨剑流（男人的浪漫）

**加点**：力量 66（双持等效 99）/ 耐力 40

**核心武器**：
- 巨剑（狮子斩战灰）
- 巨型锤矛（祈祷一击战灰）

**护符**：大壶众武 + 龙徽大盾 + 斧护符 + 绿龟

**打法**：狮子斩 → 处决 → 狮子斩 → 处决 ...

## 4. 信仰战士（万金油）

**加点**：信仰 60 / 力量 40 / 生命力 40

**核心装备**：
- 亵渎圣剑（击杀回血，推图永动机）
- 狩猎神祇大剑（黑炎伤害）

**祷告**：黄金树立誓 + 火焰赐予力量 + 黑炎庇护 + 古龙雷击

**评价**：完美的全能流派，能打能奶能 buff。
