## 🌟 S级传说武器（必拿）

### 1. 【暗月大剑】（Dark Moon Greatsword）
- **类型**：大剑
- **属性补正**：力气D / 灵巧D / 智力S
- **基础属性**：物理114 + 魔法78
- **战技**：「月光剑」—— 附魔武器，增加魔法伤害，重攻击发射月光波
- **获取方式**：
  1. 完成菈妮支线（漫长支线）
  2. 最终在月光祭坛获得
- **适用流派**：纯法师 / 魔剑士
- **强度评级**：⭐⭐⭐⭐⭐
- **点评**：法师毕业武器，月光波射程远伤害高，PVE和PVP都很强

### 2. 【玛莲妮亚的义手刀】（Hand of Malenia）
- **类型**：刀（武士刀）
- **属性补正**：力气D / 灵巧S
- **基础属性**：物理138
- **战技**：「水鸟乱舞」—— 向前突进连续斩击，最后一击浮空
- **获取方式**：
  1. 击败「米凯拉的锋刃 玛莲妮亚」
  2. 用追忆兑换
- **适用流派**：纯灵巧 / 出血流
- **强度评级**：⭐⭐⭐⭐⭐
- **点评**：灵巧流毕业武器，水鸟乱舞伤害爆炸，出手快范围大

### 3. 【亵渎圣剑】（Blasphemous Blade）
- **类型**：大剑
- **属性补正**：力气D / 灵巧D / 信仰D
- **基础属性**：物理121 + 火焰78
- **战技**：「亵渎之火」—— 释放火焰冲击波，击杀敌人回复血量
- **获取方式**：
  1. 击败「亵渎君王 拉卡德」
  2. 用追忆兑换
- **适用流派**：信仰战士 / 火焰流
- **强度评级**：⭐⭐⭐⭐⭐
- **点评**：信仰战士神器，吸血效果让生存能力大幅提升，清群怪效率极高

## ⭐ A级传说武器（强力推荐）

### 4. 【碎星大剑】（Starscourge Greatsword）
- **类型**：特大剑（双持）
- **属性补正**：力气D / 灵巧D / 信仰C
- **基础属性**：物理131 + 魔力69
- **战技**：「碎星」—— 双剑插入地面，召唤重力冲击波
- **获取方式**：
  1. 击败「碎星将军 拉塔恩」
  2. 用追忆兑换
- **适用流派**：力信战士 / 重力流
- **强度评级**：⭐⭐⭐⭐
- **点评**：双持特大剑霸气十足，碎星战技范围大伤害高，但出手较慢

### 5. 【夜与火之剑】（Sword of Night and Flame）
- **类型**：剑（直剑）
- **属性补正**：力气D / 灵巧D / 智力D / 信仰D
- **基础属性**：物理87 + 魔法57 + 火焰57
- **战技**：「夜与火之姿」—— 两种模式：
  - 轻攻击：发射彗星（魔法伤害）
  - 重攻击：喷射火焰（火焰伤害）
- **获取方式**：
  1. 卡利亚城寨 - 从屋顶跳下去的房间里
  2. 需要从城寨上部跳下来
- **适用流派**：智信双修 / 法爷
- **强度评级**：⭐⭐⭐⭐
- **点评**：曾经的版本答案，虽然被削弱但依然强力，双修流首选

### 6. 【月光大剑】（Moonlight Greatsword）
- **类型**：大剑
- **属性补正**：力气D / 灵巧D / 智力S
- **基础属性**：物理110 + 魔法82
- **战技**：「月光」—— 附魔武器，重攻击发射月光弹
- **获取方式**：
  1. 完成菈妮支线
  2. 与暗月大剑不同版本（注意区分）
- **适用流派**：法师 / 魔剑士
- **强度评级**：⭐⭐⭐⭐
- **点评**：经典武器，从魂系列传承下来的情怀武器，强度也在线

## 🛡️ B级传说武器（特定流派可用）

### 7. 【黄金律法大剑】（Golden Order Greatsword）
- **类型**：大剑
- **属性补正**：力气D / 灵巧D / 信仰D
- **基础属性**：物理120 + 圣律76
- **战技**：「黄金律法」—— 附魔武器，增加圣属性伤害，恢复血量
- **获取方式**：
  1. 击败「黄金律法的守护者」
  2. 位于巨人山顶
- **适用流派**：圣律信仰流
- **强度评级**：⭐⭐⭐
- **点评**：圣属性武器，对亡灵类敌人有奇效，但泛用性一般

### 8. 【巨剑（巨人）】（Greatsword）
- **类型**：特大剑
- **属性补正**：力气D / 灵巧D
- **基础属性**：物理164
- **战技」：「跺脚」—— 跺脚产生冲击波，然后接下劈
- **获取方式**：
  1. 巨人战争的英雄墓地
  2. 宝箱中获得
- **适用流派**：纯力量 / 猛男流
- **强度评级**：⭐⭐⭐⭐
- **点评**：纯力量玩家的最爱，面板极高，就是出手慢

### 9. 【遗迹大剑】（Ruins Greatsword）
- **类型**：特大剑
- **属性补正**：力气C / 灵巧D / 智力D
- **基础属性**：物理124 + 魔力68
- **战技**：「遗迹波」—— 释放重力波
- **获取方式**：
  1. 击败「碎星」后在红狮子城获得
  2. 或特定Boss掉落
- **适用流派**：力智双修
- **强度评级**：⭐⭐⭐
- **点评**：颜值不错，但强度中规中矩

## 🗺️ 收集路线推荐

### 前期可获得
1. **夜与火之剑** — 卡利亚城寨（利耶尼亚湖）
2. **巨剑** — 巨人战争墓地（需要钥匙）

### 中期可获得
3. **碎星大剑** — 击败拉塔恩（红狮子城 festival）
4. **遗迹大剑** — 红狮子城（碎星后）

### 后期可获得
5. **亵渎圣剑** — 击败拉卡德（火山官邸）
6. **黄金律法大剑** — 巨人山顶
7. **暗月大剑 / 月光大剑** — 菈妮支线（很长）
8. **玛莲妮亚的义手刀** — 击败玛莲妮亚（圣树）
