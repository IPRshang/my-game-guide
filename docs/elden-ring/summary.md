# 艾尔登法环 剧情讲了什么

法环的剧情是"碎片化叙事"，很多褪色者通关了还一头雾水。这篇把主线逻辑串起来。

## 一、世界背景

- **艾尔登法环**：维系交界地秩序的"规则之环"，由无上意志赐下。
- **黄金树**：法环的具象化，黄金一族统治的象征。
- **碎裂**：神人玛莉卡砸碎法环，半神们争夺大卢恩，黄金树时代崩塌。

## 二、你的身份与目标

你是"褪色者"——被黄金树剥夺恩典、放逐外界的人。黄金树重新赐下指引，召唤你回到交界地，目标是**修复法环、成为艾尔登之王**。

## 三、关键半神与势力

| 半神 | 区域 | 关键词 |
|------|------|--------|
| 葛瑞克 | 史东薇尔城 | 初始boss、联姻野心 |
| 拉塔恩 | 盖利德 | 陨石、红狮子 |
| 拉卡德 | 火山官邸 | 吞神、亵渎 |
| 玛莲妮亚 | 圣树 | 猩红腐败、女武神 |
| 蒙格特/蒙格 | 王城/地下 | 鲜血、潜行神 |

## 四、全部结局路线

1. **艾尔登之王（群星/律法/濒毁等变体）**：修复法环，不同意识形态。
2. **群星结局**：协助菈妮，送走无上意志。
3. **潜藏者结局**：支持食粪者，腐朽黄金树。
4. **雪魔女/癫火**：受癫火影响的不同收场。
