## 新手 5 条黄金法则

1. **打不过就跑** — 交界地不鼓励硬刚，等级压制非常明显
2. **优先加血量** — 前 20 级全加生命力，活着才有输出
3. **宁姆格福就能刷到 40 级** — 啜泣半岛的巨人每个 1000 卢恩
4. **骨灰是你的朋友** — 离群野狼、无头骑士、仿身泪滴，叫大哥不丢人
5. **别打守墓石像鬼** — 真的，别去。
