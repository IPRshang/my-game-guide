## 🎯 开局出身选择

| 出身 | 推荐度 | 特点 | 适合流派 |
|------|:------:|------|----------|
| 流浪骑士 | ⭐⭐⭐⭐⭐ | 高血量高负重，起始装备优秀 | 力量 / 信仰 |
| 观星者 | ⭐⭐⭐⭐ | 起始法术强力，射程远 | 纯法师 |
| 武士 | ⭐⭐⭐⭐⭐ | 打刀出血、长弓远程 | 敏捷 / 出血 |
| 囚犯 | ⭐⭐⭐ | 刺剑+魔法，灵活多变 | 敏法双修 |
| 预言家 | ⭐⭐⭐ | 起始有恢复奇迹 | 纯信仰 |

---

> 🛡️ **新玩家建议**: 选**流浪骑士**或**武士**，生存能力强，不容易暴毙。出身只影响前期，后期一切都可自由Build。
