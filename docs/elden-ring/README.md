## 一、游戏背景简介

《艾尔登法环》由 FromSoftware 与《冰与火之歌》作者乔治·R·R·马丁共同构建世界观。故事发生在「交界地（The Lands Between）」——黄金树曾赐福万物，但「艾尔登法环」破碎后，半神们为争夺碎片（大卢恩）陷入混战，世界陷入衰败。

玩家扮演「褪色者（Tarnished）」，被召唤回交界地，目标是收集大卢恩、修复法环、成为「艾尔登之王」。游戏以**高自由度开放世界 + 魂类硬核战斗**著称，几乎没有强制引导，鼓励玩家自行探索。

> 本攻略默认**不剧透 Boss 名称与剧情走向**，仅提供机制与成长思路。

## 二、核心玩法机制说明

- **开放世界魂 like**：无任务箭头，赐福（检查点）间自由探索，打不过可绕路。
- **翻滚与弹反**：翻滚有无敌帧，是闪避核心；小盾/拳套可「弹反（反击）」部分敌人，成功触发处决。
- **战灰（Ash of War）**：给武器附加战技与属性质变，决定流派走向。
- **骨灰（Spirit Ashes）**：消耗 FP 召唤助力（狼、泪滴人偶等），是新手最强容错手段。
- **灵马托雷特（Torrent）**：二段跳、快速位移，Boss 战可召唤，是走位神器。
- **赐福与升级**：赐福点兼存档、升级、洗点（需泪滴幼体）；属性点自由分配决定 Build。
- **多人联机**：地面符文可召唤他人助战（合作），或被红灵入侵（PVP），可用「罪犯本质」主动入侵。
- **黄金树幽影（DLC）**：独立地图「影之地」，难度更高，新增武器/魔法/追忆 Boss。

## 三、新手入门要点

1. **出身选「流浪骑士」或「武士」**：高血量/好武器，生存强、不易暴毙（详见下方对比）。
2. **优先加「生命力（Vigor）」**：血量永远是魂类第一属性，建议 40 级前点到 30–40。
3. **被卡关就绕路**：宁姆格福打不过？去湖之利耶尼亚、盖利德 or 地下世界（Siofra）练级，等级碾压最好用。
4. **尽早拿骨灰**：「离群野狼的骨灰」在风暴山丘墓室可获得，Boss 战召狼能分担大量伤害。
5. **多用灵马**：托雷特二段跳可越过地形与攻击，是跑图与 dodging 核心。
6. **召唤助战不丢人**：赐福点金色记号可召唤其他玩家，卡 Boss 时大胆用。
7. **别乱洗点**：洗点道具（泪滴幼体）稀有，前期确定流派再投点。

## 四、进阶技巧与策略

- **Build 方向**：出血流（尸山血河+毒雾）、纯法师（陨石杖+岩石球）、信仰战士（焰术/黄金树）、力量重击（巨星锤）——见 [流派配装](./builds)。
- **弹反时机**：人形/小型敌人弹反窗口大，大型 Boss 多用翻滚+骨灰；练弹反可大幅提速。
- **逃课路线**：利用等级差（去地下/雪山刷级）、骨灰人偶（仿身泪滴）可单刷多数 Boss。
- **战灰质变**：「寒冷」「出血」质变泛用性最高，配合对应属性点。
- **DLC 准备**：进影之地前建议等级 120+、强化 +20 以上（普通）/ +9（特殊），否则极难。
- **Switch 2 新增内容**：Tarnished Edition（2026-08-28）带来 2 个新职业（Knight of Ides、Heavy Knight）、新护甲与托雷特外观自定义，老玩家可单独购买「Tarnished Pack」（约 $4.99）。

## 常见问题

**Q1：游戏太难，是不是我不适合？**
A：魂类门槛在「学习敌人动作」而非操作。流浪骑士 + 骨灰 + 召唤，普通玩家也能通关。卡关就升级绕路。

**Q2：DLC 怎么进？需要买吗？**
A：**黄金树幽影**为付费 DLC（2024-06-21 发售），需购买；进 DLC 需在主线击败「碎片君王」后从大地图特定赐福进入。

**Q3：Switch 2 能玩吗？有什么区别？**
A：能。2026-08-28 推出 **Tarnished Edition**（含本体 + DLC + 新职业/护甲/托雷特外观）。其他平台老玩家可单独购买 Tarnished Pack 获得新内容。

**Q4：在线模式要付费吗？**
A：PS/Xbox 需会员（PS Plus / Game Pass Core），PC 免费联机。

**Q5：全成就要多久？**
A：约 150–200h，含多结局与隐藏 Boss。

**Q6：新手先推主线还是先探索？**
A：先探索宁姆格福外围练级，拿到马和骨灰后再碰第一个大 Boss（恶兆）。
