# 《艾尔登法环》护符指南

**护符是《艾尔登法环》里装备在专属栏位上的被动增益。你一开始只有少量栏位，击败关键 Boss 后解锁更多；对生存而言，一枚合适的护符往往比一次武器升级更关键。**

## 解锁护符栏位

- 你一开始只有 **1 个护符栏位**。
- 击败早期重要 Boss 会奖励一个额外栏位袋。
- 更多栏位袋来自游戏后期的 **剧情关键 Boss**。
- 到后期你最多可以同时装备 **4 枚护符**。

## 常见效果类别

| 类别 | 作用 | 何时用 |
|---|---|---|
| 减伤 | 降低受到的物理或元素伤害 | 任何流派——永远有用 |
| 属性增益 | 提升 vigor、耐力、智力或伤害属性 | 补齐短板属性 |
| 耐力 / 装备负重 | 更多耐力或更高负重 | 重甲或大盘盾流派 |
| 情境类 | 跳得更高、卢恩更多、处决更强 | 刷资源或特定 Boss |

## 怎么选一套

1. **栏位一：防御。** 减伤类护符几乎不会亏。
2. **栏位二：你流派的核心属性或伤害类型。** 与主要伤害来源匹配。
3. **栏位三：手感。** 耐力回复、装备负重或 FP 管理。
4. **栏位四：针对 Boss。** 硬仗前换上——例如针对其元素堆减伤。

## 小贴士

- **打 Boss 前换**，别在战斗中换——战斗里改不了护符。
- **元素减伤** 比看上去重要；叠加起来能让某些 Boss 变得轻松。
- **别囤"好看"的护符**——你真装备上的小幅增益，胜过仓库里那枚完美的。

## 常见问题

**Q：我能装备几枚护符？**
A：4 枚，条件是你已通过剧情进度解锁了所有栏位袋。

**Q：护符能洗点吗？**
A：护符与洗点无关——随时在菜单里自由更换即可。

**Q：哪枚护符最好？**
A：没有绝对最好的；一枚减伤护符加两枚契合流派的，是稳妥的默认组合。
