# 艾尔登法环 新手开局攻略

刚进交界地容易迷路。这篇给你一条**不绕路、能升级、能拿关键武器**的前期路线。

## 一、出生职业怎么选

- **流浪骑士**：血厚防高，新手最友好。
- **Astrologer 观星者**：远程法师，开荒安逸但脆。
- 不推荐"勇者/武士"以外的极端开局，容错低。

## 二、前期推进路线（宁姆格福）

1. **史东薇尔城前**：先清宁姆格福主线，拿"练马场"赐福点。
2. **必拿武器**：前往盖利德前，先拿**陨石杖+岩石球**（法师）或**君王军大剑**（近战）。
3. **升级优先级**：近战先点生命到 20+，再点主属性。

## 三、快速升级技巧

- 反复刷"史东薇尔城"外的士兵，或去**湖之利耶尼亚**的学院门前刷魔法师。
- 拿到金鸦盾/召唤类骨灰前，尽量靠骨灰分担伤害。

## 四、新手常见坑

- 别硬刚恶兆妖鬼，等级不够就绕路去拿强力战灰。
- 别忽视骨灰系统，仿身泪滴是中期最强助力。
