# 艾尔登法环 女武神玛莲妮亚 怎么打

玛莲妮亚（女武神）被公认为法环最难 Boss 之一，核心难点是**水鸟乱舞**和二阶段**猩红腐败**。下面按"准备 → 一阶段 → 二阶段"拆解。

## 一、开打前准备

- **推荐等级**：150+，血量 50 以上更稳。
- **推荐流派**：出血流（尸山血河 / 双匕首），能快速压血线减少她出招次数。
- **骨灰**：仿身泪滴（人偶）最稳，能分担水鸟锁定。
- **护符**：龙徽大盾、大壶众武、腐败眷属的欢愉。

## 二、一阶段：水鸟乱舞怎么躲

水鸟乱舞有三段，最稳应对：

1. **起手翻滚**：她跃起瞬间向**侧后方**翻滚，躲第一段。
2. **贴身绕后**：落地后立刻绕到她背后，第二段基本打不到。
3. **拉开距离**：第三段前冲，向后跑或翻滚避开。

> 新手可用"冻霜踏地"或远距离法术在她出水鸟前压血，逼她早进二阶段。

## 三、二阶段：猩红腐败

- 进二阶段瞬间会炸一圈猩红腐败，提前吃**净化苔藓**或拉开距离。
- 她攻击更密集，但动作前摇更长，靠泪滴骨灰拉仇恨时大胆输出。

## 四、一句话总结

女武神是"背板 Boss"——把水鸟乱舞的三段时机练熟，配合出血流快速压血，就能稳定过。更多 Boss 见 [全 Boss 攻略](./bosses)，配装见 [流派配装](./builds)。
