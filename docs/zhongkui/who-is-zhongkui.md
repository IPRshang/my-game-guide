# 钟馗是谁？道教捉鬼天师与游戏设定

> 一句话：钟馗是中国民间信仰里的「**赐福镇宅圣君**」与 **捉鬼除妖神祇**，游戏科学据此把他设为《黑神话：钟馗》的主角——与孙悟空毫无关系。

## 一、历史上的钟馗

- 钟馗相传为 **唐代进士**，因相貌异于常人、刚正不阿，死后被封为「伏魔大神」；
- 在民间信仰中，他是 **驱邪、斩鬼、赐福镇宅** 的象征；
- 传统年画、戏曲里常见「钟馗捉鬼」「钟馗嫁妹」等题材。

## 二、民间形象：赐福镇宅、捉鬼除妖

- 钟馗的核心标签是「**捉鬼天师**」，游走于人间与幽冥之间；
- 与孙悟空的「齐天大圣 / 天命人」路线完全不同；
- 这让他天然适合「动作 RPG + 鬼怪世界观」的题材。

## 三、游戏里的钟馗

游戏科学把神话做了玩法化落地：

- **主角定位**：可操控的剑客 / 捉鬼者；
- **核心战斗**：单手剑 + 格挡弹反 + 火雷符咒；
- **统辖八万鬼卒**：转成「捕捉 → 召唤 → 附身」的战斗循环（见 [战斗系统详解](/zhongkui/combat)）；
- **题材来源**：散落民间传说、戏曲、历代文学，而非单一文本。

## 四、钟馗 ≠ 孙悟空

| 维度 | 钟馗 | 孙悟空（天命人） |
|---|---|---|
| 来源 | 道教 / 民间传说 | 《西游记》 |
| 身份 | 捉鬼天师 | 齐天大圣 / 天命人 |
| 战斗 | 单手剑 + 弹反 + 符咒 | 金箍棒 + 变身 |
| 剧情关联 | 与悟空无关 | — |

详见 [钟馗 vs 悟空：区别在哪](/zhongkui/vs-wukong)。

## 五、为什么选钟馗做新主角？

- 「黑神话」品牌要做的不是某一条故事线的续作，而是 **中国神话宇宙** 的多主角展开；
- 钟馗自带「捉鬼 + 幽冥 + 符咒」的强动作基因，差异化明显；
- 与悟空形成「一个打天、一个捉鬼」的互补叙事。

## 常见问题

**Q：钟馗 和 孙悟空 是同一个故事吗？**
A：不是。两者同属「黑神话」品牌，但主角、题材、剧情互不关联。

**Q：钟馗 是真实历史人物吗？**
A：钟馗是民间信仰与传说人物，历史上是否真有其人并无定论，传说多附会唐代。

**Q：游戏里钟馗 能变身吗？**
A：演示展示的是「召唤 / 附身鬼卒」机制，与悟空的七十二变不同。
