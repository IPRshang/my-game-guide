# 黑神话：钟馗 PC 配置要求（估算）

> ⚠️ 本文为 **估算配置**，非官方数据。游戏科学尚未公布《钟馗》最终配置。以下基于 UE5 引擎、8/20 实机画面表现，以及《黑神话：悟空》的硬件需求推演，仅供购机 / 升级参考，发售前以官方公告为准。

## 一、为什么是估算？

- 钟馗基于虚幻引擎 5（UE5），实机呈现 21:9 超宽屏与自然光照；
- 大量阴天 / 雾气场景对显存压力更大；
- 官方明确处于研发早期，最终优化未定。

## 二、最低配置（估算）

| 项目 | 估算规格 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| CPU | 6 核，如 i5-8400 / R5 1600 |
| 内存 | 16GB |
| 显卡 | GTX 1060 6GB / RX 580 8GB |
| 存储 | 130GB SSD（强烈不建议机械硬盘） |
| 帧率预期 | 1080P 低画质，开 FSR/DLSS 后 30–45 帧 |

## 三、推荐配置（估算）

| 项目 | 估算规格 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| CPU | i7-10700 / R7-5800X |
| 内存 | 32GB（大场景 / 雾气更吃内存） |
| 显卡 | RTX 3060 / RTX 4060 / RX 6700 XT |
| 存储 | 130GB SSD |
| 帧率预期 | 1080P 高画质 60 帧 |

## 四、2K 光追配置（估算）

| 项目 | 估算规格 |
|---|---|
| CPU | i7-13700 / R7-7700X |
| 内存 | 32GB |
| 显卡 | RTX 4070 Ti / RX 7900 XT 及以上 |
| 存储 | 130GB SSD |

## 五、易漏要点

- **硬盘必须 SSD**：130GB 仅限 SSD 固态硬盘，机械硬盘会加载卡顿甚至无法启动；
- **显卡依赖 DLSS/FSR**：最低配置需开启帧生成以维持帧率；
- **内存吃紧场景**：雾气及大场景环境更耗内存，32GB 为推荐下限；
- **最终配置待公布**：以上非最终版，发售前官方会更新准确数据。

## 常见问题

**Q：钟馗 需要多少存储空间？**
A：估算 130GB SSD，机械硬盘不推荐。

**Q：支持 PS4 / Xbox One 吗？**
A：不支持。仅登陆 PS5 与 Xbox Series X|S（见 [平台与购买](/zhongkui/platforms)）。

**Q：现在就能按这个配置买电脑吗？**
A：若预算够，按推荐配置买不会亏；但建议等官方配置公布后再最终确认。
