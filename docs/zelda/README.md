## 🛠️ 核心机制：余料建造

王国之泪最大特色——几乎所有物品都能通过「余料建造」融合：

| 基底 | 推荐余料 | 效果 |
|------|----------|------|
| 大师剑 | 白银莱尼尔角 | 攻击力 +55，极其锋利 |
| 卓拉枪 | 冰蝙蝠翅膀 | 湿润时攻击翻倍 + 冰冻 |
| 格鲁德刀 | 白银人马角 | 高耐久 + 超高面板 |
| 近卫盾 | 大炮 | 盾反=远程炮击 |
| 火箭盾 | 火箭 | 盾跳即可飞天 |

---

> 🏗️ **最强提示**: 不要只依赖战斗——活用「究极手」和「蓝图」建造载具、桥梁、飞行器，很多解谜可以完全绕过。
