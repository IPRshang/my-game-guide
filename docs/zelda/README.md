## 一、游戏背景简介

《塞尔达传说：王国之泪》是《旷野之息》的直接续作。故事紧接前作，海拉鲁城堡升空、神秘「 cataclysm」降临，林克与塞尔达探索地底深处时遭遇变故，塞尔达失踪。玩家操控林克，借助全新的「左手之力」在 **天空、地表、地底** 三层世界展开冒险，揭开海拉鲁远古秘密。

游戏最大特色是**物理沙盒式创造**：前作的「希卡之石」能力被全新的「左纳乌装置」取代，玩家几乎可以建造任何载具、器械与机关，自由度极高。

> 本攻略默认**不剧透主线剧情与关键区域名称**，仅提供机制与探索思路。

## 二、核心玩法机制说明

- **四大能力（来自左手）**：
  - **究极手（Ultrahand）**：抓取/拼接物体，是建造载具、桥梁、机械的核心。
  - **余料建造（Fuse）**：把武器/素材融合到装备上，定制攻击与属性（如木棒+岩石=锤）。
  - **通天术（Ascend）**：向上穿过头顶物体直达上方，解谜/登高神技。
  - **倒转乾坤（Recall）**：让物体倒放运动，可「搭乘」落石/陷阱反向上行。
- **左纳乌装置（Zonai Devices）**：电池驱动的小车、风扇、火箭、平衡器、操纵杆等，配合究极手造载具/飞行器。
- **蓝图（Autobuild）**：记录你造过的结构，一键复现，是后期效率关键。
- **三层地图**：天空岛（初始）、地表（旷野之息海拉鲁）、地底（黑暗洞窟，需发光资源照明）。
- **神庙与呀哈哈**：神庙练能力/拿心心；呀哈哈（Korok）提升武器/盾牌/弓容量。
- **料理与药物**：食材组合出回复/攻防/耐寒耐热等效果，详见 [全料理](./cooking)。

## 三、新手入门要点

1. **先吃透四大能力**：天空岛教学务必练熟，尤其究极手与通天术——它们是全程刚需。
2. **余料建造融合武器**：木棍+任何素材都能变武器，前期别嫌攻击低，融合是关键。
3. **尽早下地底探索**：地底有「光明花」与大量左纳乌矿，是电池与装置的材料来源。
4. **收集呀哈哈扩容**：武器/盾/弓容易坏，多找呀哈哈提升携带上限最实在。
5. **学做基础载具**：风扇+平台=风力车，火箭+平台=飞行器，跑图效率翻倍。
6. **料理常备**：出门前做几份「防御+攻击」料理，Boss 战容错大幅提升。
7. **善用通天术与倒转**：卡地形时这两招往往有奇效，比硬爬省力。

## 四、进阶技巧与策略

- **蓝图复用**：造好常用载具后存入蓝图，一键召唤，省去每次拼装。
- **左纳乌电池管理**：电池靠地底「左纳乌核心」升级，优先堆到够飞/够跑。
- **余料组合思路**：远程用「弓+果实」自动瞄准；破防用「锤+岩石」；元素用「武器+冰/火/雷果」。
- **地底速刷**：地底有大量敌人掉高级素材，是毕业装备的主要来源。
- **amiibo（2025 起支持）**：Sidon/Tulin/Yunobo/Riju amiibo 可获专属装备，Switch 2 Edition 可用。
- **速通向**：熟练究极手造「火箭盾跳」可无视地形直抵目标，是世界纪录级技巧。

## 常见问题

**Q1：没玩过旷野之息能直接玩王国之泪吗？**
A：可以，剧情独立且新手友好；但玩过前作会对地图与角色更有共鸣。

**Q2：Switch 2 版有什么区别？**
A：**Switch 2 Edition**（2025-06 起）帧率/分辨率提升，并支持 **ZELDA NOTES**（官方 App，含地图标注、每日奖励等）。旧 Switch 存档可继承。

**Q3：有 DLC 吗？**
A：王国之泪**官方未推出付费 DLC**（ unlike 旷野之息的 DLC 通行证）。后续仅为免费修复补丁（最新 Ver. 1.4.3，2026-02）。

**Q4：武器总坏怎么办？**
A：这是系列特色。多找呀哈哈扩容 + 余料建造用便宜素材当消耗品，珍贵武器留 Boss。

**Q5：地底太黑怎么办？**
A：地底遍布「光明花」可点亮区域，身上带「光亮花/萤火虫」类素材也能临时照明。

**Q6：需要联网吗？**
A：单机全程离线。ZELDA NOTES 需联网与任天堂账号，非必需。
