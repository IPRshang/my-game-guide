## 🕳️ 一、如何进入

地表各处「**深渊 Chasm**」直通地底；首次可经海拉鲁城堡下方主深渊（来源：HyruleArchive / GamerGuides / SegmentNext）。

- 下落时**开滑翔伞**控落点，避开底部瘴气池。

---

## ☠️ 二、瘴气（Gloom）——核心危险

踩到瘴气会**永久减少心数上限**（非临时），普通食物无法恢复（来源：HyruleArchive / DualShockers / SegmentNext）。

| 恢复方法 | 说明 |
|----------|------|
| **向阳花（Sundelion）料理** | 天空岛黄花，每朵约恢复 1 心（来源：HyruleArchive） |
| **站在已激活的光明根光环内** | 瞬间恢复全部瘴气受损心（来源：HyruleArchive） |

- **提示**：瘴气手（Gloom Hands）出现后 **Phantom Ganon** 会随即登场，用火属性远程优先清场（来源：HyruleArchive）。

---

## 💡 三、光源解决方案

| 方案 | 说明 |
|------|------|
| **明亮花种 Brightbloom Seeds** | 可手抛 / 绑箭射出，落地生根长期发光，是最优解（来源：SegmentNext / GamerGuides） |
| **光明根 Lightroot** | 地底版「神庙」，激活即点亮地图 + 快速传送 + 恢复瘴气心；位置与地表 120 神庙一一镜像，名字是神庙名倒序（来源：HyruleArchive） |
| **矿工服 Miner's Armor** | 发光照明，可从了望台 Bargainer 雕像用 Poes 兑换（来源：GamerGuides / SegmentNext） |

---

## 🛠️ 四、探索技巧

- **走高处**：树木 / 矿车轨道 / 废墟通常无瘴气，可逐树跳跃（来源：DualShockers）。
- **造左纳乌载具**：装轮子 / 风扇的滑板可掠过瘴气不接触（来源：DualShockers / GamerGuides）。
- **用上升（Ascend）** 穿过天花板绕过瘴气区。
- 收集 **Zonaite（左纳矿）**、**Poes**，在 Bargainer 雕像换强力装备。

---

## ⚠️ 五、常见坑

| 误区 | 真相 |
|------|------|
| 瘴气掉的心靠普通食物回 | 必须向阳花料理或光明根光环 |
| 靠近光明根就能回血 | 仅「站光环里」才恢复，靠近不生效（来源：HyruleArchive 指明此为常见误解） |
