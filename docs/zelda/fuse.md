# 《王国之泪》余料建造指南

**余料建造让你在《王国之泪》里把几乎任何物体附着到武器、盾牌或箭上。融合的材料会改变武器的伤害、耐久或行为——而因为游戏里多数武器耐久很低，余料建造是维持你输出竞争力的主手段。**

## 余料建造做什么

- **武器**：附着材料以提升攻击力或附加效果（元素、爆炸等）。
- **盾牌**：附着物体获得功能性——比如临时雪橇或防御尖刺。
- **箭**：附着材料改变箭的效果——元素爆发、爆炸或追踪。

## 实用组合

1. **武器上装强力角或爪**——最稳定的直接伤害提升。
2. **元素材料**——附加火、冰或雷，针对敌人弱点。
3. **箭上装炸药桶**——小心使用时的高效清群。
4. **盾上装火箭或风扇**——开阔地带的移动与功能解法。

## 耐久为什么重要

- 多数地表武器很快碎，所以 **余料建造等于放大每把武器的产出**。
- 把贵重材料融到快碎的武器上是浪费——先看好耐久。
- 带几样强材料，比囤一堆弱材料有用。

## 小贴士

- **硬仗前先融合**，别在战斗中融——菜单暂停会让你暴露。
- 在游戏允许处 **剥掉不好的融合**，别浪费好材料。
- **元素融合也是解谜工具**，不只是战斗升级。

## 常见问题

**Q：什么都能融合吗？**
A：多数物体与魔物部位可融合；少数独特物品不行。

**Q：融合会消耗材料吗？**
A：会——附着物作为武器一部分被消耗，直到武器碎掉。

**Q：什么给的伤害提升最大？**
A：通常看你手头最强的魔物部位；角与爪成长性很好。
