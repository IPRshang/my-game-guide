## 📊 克洛格种子总览

克洛格种子（Korok Seeds）是塞尔达系列的经典收集品，用于扩充武器袋、弓箭袋和盾牌袋的容量。

| 区域 | 数量 | 占比 | 收集难度 |
|------|:----:|:----:|:--------:|
| 地面（Surface） | 640 | 71% | ⭐⭐⭐ |
| 天空（Sky） | 160 | 18% | ⭐⭐⭐⭐ |
| 地下（Depths） | 100 | 11% | ⭐⭐⭐⭐⭐ |
| **总计** | **900** | **100%** | |

> 💡 **扩容需求**：
> - 武器袋：从8格扩容到20格，需要441颗种子
> - 弓箭袋：从5格扩容到14格，需要232颗种子
> - 盾牌袋：从4格扩容到16格，需要291颗种子
> - **全部扩容总计：964颗**（实际只有900颗，无法全满）

## 🎯 克洛格谜题类型

### 常见类型
| 类型 | 描述 | 解法 |
|------|------|------|
| **石头堆** | 三堆石头，其中一堆少一块 | 把缺失的石头放上去 |
| **花朵** | 一朵花，踩上去会出现更多 | 按顺序踩完所有花 |
| **橡果** | 树洞里有橡果 | 用箭射橡果 |
| **金属球** | 大坑旁边有金属球 | 用究极手把球放进坑里 |
| **木桩** | 几个木桩，其中一个位置不对 | 把木桩移到正确位置 |
| **蜡烛** | 一排蜡烛，有的灭了 | 点燃所有蜡烛 |
| **风车** | 风车旁边有靶心 | 在风车停止前射中所有靶心 |
| **漂浮方块** | 空中有方块 | 用究极手拼出正确形状 |
| **落叶** | 树底下有落叶堆 | 烧掉落叶堆 |
| **苹果** | 树上有苹果，其中位置不对 | 把苹果摆到正确位置 |

### 新增类型（王国之泪特有）
| 类型 | 描述 | 解法 |
|------|------|------|
| **左纳乌装置** | 需要用左纳乌装置触发 | 安装对应装置并启动 |
| **洞窟入口** | 洞窟入口有谜题 | 解开后进入洞窟 |
| **天空岛** | 天空岛上的特殊谜题 | 利用天空岛机制 |
| **地底发光** | 地下发光种子附近 | 在黑暗中找到发光点 |

## 💡 高效收集技巧

### 1. 按区域系统收集
```
解锁鸟望台 → 标记该区域所有克洛格 → 逐个收集 → 下一个区域
```

### 2. 利用地图标记
- 用不同颜色的图钉标记不同类型的克洛格
- 收集过的可以删掉或打勾
- 建议使用互动地图辅助

### 3. 必备道具
| 道具 | 用途 |
|------|------|
| **光亮花种子** | 地下照明必备 |
| **火箭** | 快速升空到天空岛 |
| **弓箭 + 大量箭** | 射橡果/靶心/蜡烛 |
| **火焰果/火焰杖** | 点燃蜡烛/烧落叶 |
| **究极手** | 移动石头/金属球/方块 |
| **通天术** | 快速从地下回到地面 |

### 4. 扩容优先级
1. **武器袋**（最优先）—— 武器消耗最快
2. **盾牌袋**（其次）—— 盾牌也经常碎
3. **弓箭袋**（最后）—— 弓箭相对够用

## 🗓️ 收集路线推荐

### 前期（0-100颗）
1. 初始空岛 + 初始台地周边
2. 中央海拉鲁平原
3. 卡卡利科村周边
4. 沿路顺手收集

### 中期（100-400颗）
1. 按地区逐个清理
2. 每解锁一个鸟望台就清完该区域
3. 天空岛顺路收集
4. 优先扩容武器袋到15格左右

### 后期（400-900颗）
1. 查漏补缺
2. 地下区域全收集
3. 天空岛全收集
4. 使用互动地图标记

## 🔍 难找的克洛格位置

### 容易漏掉的位置
1. **建筑内部** — 废墟/洞窟/井里
2. **树顶上** — 需要爬树或飞上去
3. **瀑布后面** — 很多藏在瀑布后面
4. **小岛** — 湖里/海里的小岛
5. **悬崖边** — 沿着悬崖找
6. **地下深处** — 地下最深处的角落

### 搜索技巧
- 听到「克洛格音效」就说明附近有
- 仔细观察不自然的地方（石头堆、单独的花）
- 用望远镜扫描
- 高处视野好，容易发现
