# 《王国之泪》防具指南

**《王国之泪》里的防具提供防御，集齐一整套通常会额外给一套套装加成。在大精灵处升级部件能提升防御，并在更低投入下解锁这些加成，所以"升级什么"比囤部件更重要。**

## 防具怎么运作

- 每件部件提供 **防御点**；总和决定你受到的伤害。
- **套装** 在集齐时给加成——通常是元素抗性、攻击提升或移动增益。
- **升级** 需要材料与卢比，在解锁后的大精灵之泉进行。
- 有些防具是 **情境型**——抗寒、抗热或潜行——而非纯战斗装。

## 优先升级什么

1. **一套通用装**，你会最常穿的那套。
2. **元素抗性套**，给需要它们的区域用。
3. **攀爬或移动套**——省下常备消耗品的手感提升。
4. **先升满一套再铺开**——前期防御成长比多样性更重要。

## 套装加成

- 通常当你穿齐一整套 **且至少各升一级** 时解锁。
- 效果从 **攻击提升**、**元素免疫** 到 **减少 stamina 消耗** 不等。
- 投资前先看套装效果——有些加成只在特定情境才有用。

## 小贴士

- **元素抗性可以替代料理**——穿对防具能腾出背包格。
- **别卖防具**——你淘汰的部件常常用于完成度或特定解谜。
- **染色与防具被动能和食物叠加**，但和同类食物效果不叠加。

## 常见问题

**Q：防具在哪升级？**
A：在大精灵之泉，随你逐一帮助每位大精灵逐步解锁。

**Q：我需要每一套防具吗？**
A：不需要。几套升好级的就几乎覆盖所有情况。

**Q：防具影响潜行吗？**
A：影响——有些套装与部件能降低你发出的声响、以及敌人发现你的速度。
