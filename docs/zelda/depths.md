# 《王国之泪》地底指南

**地底是一大片与《王国之泪》地表地图镜像对应的黑暗地下世界。它的危险主要来自黑暗与瘴气，而非敌人——所以核心技巧是照亮道路、管理瘴气伤害，并知道地下到底有什么值得收集。**

## 下地之前

1. **带光源**——能照明的道具或左纳乌装置必不可少。
2. **备好能恢复瘴气心心的回血**——普通食物治不了瘴气损失的红心。
3. 若有，带 **瘴气抗性防具**——减少持续掉血。
4. **解锁光根（Lightroot）**——每个光根会永久照亮地底一片区域。

## 怎么探索

- **光根优先**——它们揭示地图，让其它一切都变容易。
- 地底布局 **镜像地表**——上方地标对应下方特征，有助于导航。
- **裂隙（Chasm）** 是主要入口；在地表地图上标好你找到的裂隙。
- **别摸黑乱走**——没光你会错过崖壁与资源。

## 什么值得收集

- **左纳乌能量与装置**——地底是建造材料的最佳来源。
- 地表找不到的 **独特矿石与制作材料**。
- **光根本身**，既是进度也是便利。
- **Boss 重战**——某些强敌在下方重现，适合刷强力部件。

## 小贴士

- **别逢怪必打**——黑暗里机动性胜过战斗。
- **利用地形**——高处结构让你滑翔越过危险。
- **定期回地表** 补给与重置。

## 常见问题

**Q：我的红心怎么消失了？**
A：瘴气伤害会暂时移除最大红心；你需要特定回血或安全区才能恢复。

**Q：地底是主线必须的吗？**
A：对主剧情是可选的，但它藏着重要资源与进度道具。

**Q：地底下怎么看得见？**
A：光源、光根，以及某些防具或道具——多备几种方案。
